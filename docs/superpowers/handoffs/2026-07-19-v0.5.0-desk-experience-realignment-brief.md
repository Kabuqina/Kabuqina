## 1. 北极星

> **v0.5.0 要产出一张真正能让学生学习的书桌。小娜是桌上那杯引导、辅助、陪伴学生的
> 咖啡。学生始终是需要学习、正在学习、完成学习动作的人。**

这句话的设计含义：

- 书桌与咖啡杯不是装饰主题，而是产品的空间模型、操作模型和氛围基调；
- 拟物必须用 DOM/CSS/轻量 SVG 顺利实现，不依赖复杂 3D、重资产或位图纹理；
- 学生的纸页、答案、练习、修正和积累永远是视觉与交互主体；
- 小娜可以引导、解释、递提示、陪伴和见证，但不接管作答面、不替学生完成学习动作；
- 流畅不是减少桌上物件，而是让稳定物件各守其位、当前任务自然聚焦、跨面往返不破坏
  学习现场。

一句产品化表达：

> **学生坐下就能从书签继续；在笔记本里读、写、练、改；需要时碰一下咖啡杯，小娜带着
> 当前页靠近；对话结束后，学生仍在原来的纸页上继续学习。**

## 2. 本轮纠偏

以下误读明确作废：

- 不把书桌拟物降级为可选皮肤或氛围装饰；
- 不隐藏书堆、笔记本、卡片盒、杯子来换取所谓“极简”；物件始终可发现，渐进呈现发生在
  物件内容与当前密度中；
- 不再提出三套互相竞争的书桌母版；宽屏位置已经 owner 确认；
- 不把“学生是否仍是学习者”当测试变量；学生主体性是硬约束；
- 不把小娜理解成悬浮 Chat 按钮；杯子是她在书桌上的本体、在场方式与语义入口；
- 不用当前灰阶原型中为裁决服务的内部说明、边框和三栏密度推导最终视觉。

## 4. 单一 canonical 体验流

### 4.1 坐下

冷启动进入完整书桌。学生首先看到当前本、书签下一步和卡片盒到期；书立、材料书、工作夹
和杯子稳定在各自位置。当前只有一个主动作：继续书签、开新本或处理明确 recovery。

### 4.2 翻到当前页

点击书签或笔记本后，本子扩大为 focused surface；书立、材料、卡片盒和杯子退到桌边但不消失。
这是同一张桌子的密度变化，不是跳进另一套 Dashboard。

### 4.3 学习与作答

本页只展开当前真实 activity。题干、学生输入和当前反馈形成一条阅读顺序；相关参考作为页边
折页取用；到期复习和 Activity 不自动打断。

### 4.4 检查与修改

检查结果在原页出现，至少包含：

1. **你已经说明清楚的部分；**
2. **仍需补充或修正的部分；**
3. **下一步可执行动作。**

学生可以立即修改同一份答案。确定性结果、语义建议和小娜提示不得混成一个“AI 判断”。

### 4.5 碰一下咖啡杯

杯子回应并带上当前 `space/page/activity/focus/return`。P0 baseline 可以进入完整课程 Chat；
若 wide sidecar 最终通过 E3/E4，它必须复用同一 presenter/state，并保证题干、答案和检查动作
仍可读、可操作。否则不启用 sidecar。

### 4.6 小娜陪着继续

默认辅导节奏：

```text
确认学生卡在哪里
  → 给一级提示
  → 邀请学生先试一步
  → 再提示或解释
  → 学生显式请求时给完整解法
  → 返回原页继续写
```

这不是限制学生必须逐级闯关；“直接解释/直接答案”仍可显式选择，但不作为默认抢答。

### 4.7 回到纸页

返回恢复同一页、同一题、同一答案、同一 semantic scroll/focus。小娜最后一条建议可以以
低干扰页边提示短暂保留，并提供明确“继续修改”动作；它不自动写入学生答案。

## 5. 美术设计的 CSS 边界

下一步美术不是重新选风格，直接消费已通过的 Style Tile：

- 桌面：暖米色/深靛渐变；左上统一光源；投影落向右下；
- 纸面：实心 `paper` + 极轻 SVG noise；留白页更轻；
- chrome：`kq-glass` 半透明磨砂；纸面与 chrome 靠材质区分，不靠新增色系；
- 主色：薰衣草墨；暖点：拿铁色，优先用于书签、杯中咖啡和少量陪伴提示；
- 阴影：墨色低透明近影 + 柔和远影，避免纯黑厚重阴影；
- 圆角与线宽：继承 Style Tile 的活页/按钮/卡片/本子层级和 lucide 2px 语言；
- 草稿/确认：铅笔与落墨使用形态、字体、标签和容器共同区分，颜色不单独承载状态；
- 动效：只表达翻页、换本、杯子回应、工作夹抽出和 surface 退场/返回；支持 reduced motion；
- 杯子热气、纸纹和光斑一律 `aria-hidden`，不能成为唯一状态提示。

6. owner 确认后再把冻结稿交给原型/实现 session，按 JIT slice 修改。

## 8. 完成定义

本轮设计校准完成时应能证明：

- 画面首先是一张可信、可操作的学生书桌，不是带书桌名词的 Dashboard；
- 学生从坐下到继续学习不需要先理解产品 IA；
- 当前本页与当前动作始终是主角，稳定桌上物件保持可发现；
- 检查答案产生可继续学习的反馈，不停在“已检查”；
- 小娜从杯子进入，带着当前页帮助，但不覆盖或改写学生答案；
- full/sidecar/direct presentation 不产生第二份会话状态；
- 返回后原学习现场完整，并有明确下一步；
- 视觉全部可由现有 React/DOM/CSS/轻 SVG 路线完成；
- 普通宽屏忠实继承场景母版，窄窗/200%/读屏语义等价；
- 当前决策原型仍被标记为工具，不被误称为最终设计。
