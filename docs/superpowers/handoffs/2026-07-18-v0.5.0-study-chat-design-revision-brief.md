## 3. P0：不修完就不能继续裁决

### P0-1 · 让 Wide 原型真正具备测试条件

当前外层 iframe 被限制为 `max-width: 736px`，这会把 sidecar 和 Study 强行塞进中窗宽度。
修订要求：

- `W01/W02/W03` 的**逻辑画布宽度至少 1280px**，建议 1280×800 或 1366×768；
- 若承载原型的宿主只能显示约 736px，使用 scale-to-fit 或独立横向 preview，不能把逻辑画布
  本身缩成 736px；
- contextual Chat 宽度保持 360–420px；
- sidecar 打开后，中央 Study 仍有可读宽度、主要按钮可操作，不能出现第四列；
- Chat surface 使用不透明/足够遮挡背景的 panel；不能让 Study 文本穿过 Chat 文本；
- 至少提供两个明确切换项：`Overlay right region` 与 `Compress right region`；
- card box 的退让/遮挡必须可恢复，关闭 Chat 后位置稳定；
- frame 内明确写 `TO-TEST`，不能让默认值看起来像最终决定。

**通过标准：** `W03` 中无文字重叠、无按钮覆盖、Chat ≥360px、Study 可读且可继续操作。

### P0-2 · 恢复正确的产品 IA 与 first-sight

修订后的 `W01 Desk Idle` 必须在第一视口同时出现：

- 书立/空白本：`换课 / 开新本`；
- 左桌角书堆：只表示当前课程 canonical `source_refs` 可证明的**本课已引用材料**；
- 中央课程笔记本；
- 明确书签：回答“上次学到哪里 / 下一步”；
- 右侧卡片盒 + 真实 due badge：回答“今天复习什么”；
- 右下小娜杯 + `问小娜`；
- 一只从笔记本前缘/下层露出的工作夹，含两个可操作文字入口：`＋制作`、`成果`；
- product chrome 中的 Activity/Recent。

同时修正：

- 一级目的地只显示 `学习 / 对话`；
- `成果` 不得与 `学习` 同级；`制作` 不是顶级 hub；
- `Activity/Recent` 不进入课程正文或卡片盒，只能留在 chrome；
- 卡片盒只显示当前课程 due，不显示 `Activity · 3 条`；
- 左书堆不得放“高等数学 / 线性代数”等跨课程列表；改用真实材料名，例如
  `教材 §2.3`、`微积分习题集 p.41`；
- `制作 / 成果` 不能只是静态说明文字，必须是两个可聚焦动作。

**通过标准：** 五秒观察能指出 current/new course、bookmark next、due review、Chat、
Create/results 与 Activity/Recent，且每个对象语义与 handoff 一致。

### P0-3 · Stop 必须保留已展示的部分回答

当前 streaming 文本只在 render 时临时创建；Stop 后会消失，却宣称“已生成内容仍保留”。

修订要求：

- partial assistant response 必须存在 state 中；
- Stop 后将 partial 内容提交为 `stopped/partial` 消息，或诚实显示“已停止，未保留部分回答”；
- 推荐保留 partial，并以文字 `已停止` 区分；
- 收起/展开/full/direct 切换后 partial 仍相同；
- Stop 不创建第二 session，也不清空 composer/return target。

**通过标准：** 生成中点击 Stop → 收起 → 重开/展开，已经看见的文字仍存在且状态诚实。

### P0-4 · return target 和真实 focus 必须一致

当前文案写 `练习 3 · 第 2 步`，实际 focus 被送到 `继续第 3 题` 按钮。

修订要求：

- 在 Study 中建立真实、可聚焦的 `练习 3 · 第 2 步` activity/heading；
- `return_target`、可见文案、返回后的滚动位置与 focus 指向同一对象；
- direct full Chat、expanded Chat、Return button 和 Escape 使用同一 return helper；
- return target 被删除时，显示“原位置不可恢复”，回到课程安全概览；
- 增加 `W07 Returned Study` 和 `W07b Missing Return Target` 两个状态。

**通过标准：** 返回后读屏/键盘焦点准确落在“第 2 步”，不是页面顶端或第 3 题按钮。

## 4. P1：完成 P0 后必须收口

### P1-1 · 完整的 frame/state 集

原型必须可独立进入并明确标识：

| ID | 必做状态 |
|---|---|
| `W01` | Wide Desk Idle |
| `W02` | Cup Focused，显示可见 focus ring |
| `W03A` | Sidecar Overlay |
| `W03B` | Sidecar Compress |
| `W04` | Streaming + Stop + user scrolled up |
| `W05A` | Provider Blocked |
| `W05B` | Network Error |
| `W05C` | Focus/return target missing |

| `N01` | Narrow full route |
| `Z01` | Real 200% reflow |
| `G01` | Ordinary Chat，与 course Chat 对照 |

### P1-2 · Medium 必须是真 modal drawer

- panel 使用不透明 background，视觉上与背景明确分层；
- `role=dialog` + `aria-modal=true` + heading/`aria-labelledby`；
- inert/隐藏的是 dialog 外**全部产品内容**，包括 toolbar、nav、session strip 和 Study；
- focus trap 只计算可见且可聚焦的控件，不能包含 `[hidden]`/`display:none`；
- blocked/error 打开时初始焦点进入恢复动作，正常态才进入 composer；
- Escape 关闭最内层 presentation，不停止生成；
- 关闭后恢复准确 invoker。

### P1-3 · Narrow 是 route，不是 modal

- `N01` 使用 full-height/single-route Chat；不得设置 `aria-modal`；
- 始终显示明确 `返回学习 / 返回练习 3 · 第 2 步`；
- narrow Study flat flow 不得 `display:none` 丢掉材料或卡片盒事实；改写为普通 section：
  current context → next/recovery → due → Activity → Study → materials/drafts → Create/results → Chat；
- 关闭/返回不依赖浏览器历史猜测。

### P1-4 · 200% 必须是真实验证

- 不再用 `14px → 20px` 冒充 200%；
- 使用真实 browser zoom 200%，或用等价 50% CSS viewport + 2× user scale 做可验证 fixture；
- 检查无横向滚动、无内容丢失、无重叠、focus 可见；
- 保存 `Z01` 截图并注明 viewport、zoom 和测试方式。

### P1-5 · streaming、unread 与 scroll anchor

- 用户向上阅读时不强制滚到底；
- `跳到最新消息（n）` 必须真的滚到最新消息，并保留/更新 scroll anchor；
- unread 不仅在 Chat 收起时产生，也覆盖“Chat 打开但用户离开底部”；
- 收起期间生成完成时，杯子或可读文字显示 `有新回答`，不能把 unread button 藏在 hidden Chat 内；
- transcript 更新不能用全量 `replaceChildren()` 破坏真实 scroll continuity。

### P1-6 · 状态与可访问语义

- full Chat 时隐藏 `展开完整 Chat`，不要同时显示“已经展开”和“展开”；
- Chat header 文案使用 `与小娜对话`；模式说明另放 secondary copy；
- visible heading + `aria-labelledby`，不要只依赖静态 `aria-label="课程 Chat"`；
- 当前一级导航使用 `aria-current="page"`；
- blocked/error 区使用合适的 status/alert，并关联恢复动作与 composer；
- fault 注入时不要让后台 timer 继续偷偷完成另一条“成功回答”；
- IME 同时检查本地 composing state 与 `event.isComposing`；
- 提高 muted 小字/ghost control 对比度，12px 正文风险项至少满足 4.5:1。
