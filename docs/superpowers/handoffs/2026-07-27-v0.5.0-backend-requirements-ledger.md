## B-1 `P1` token 用量聚合

**前端形态：** 设置 →「模型」tab 一节，**只报 token 数，不折算金额**
（owner 定：定价/折扣/缓存命中都不在我们手里，报假精度的钱比不报更糟）。
按**本周 / 本月 + 按课程分组**展示，低强调数字，不做趋势图。

**好消息：数据已经落库，不需要新埋点。**
`hermes_core/learning/tutor_runtime_store.py` 的 `tutor_provider_attempts` 表
（建表在同文件 L214 起）已有：

| 列 | 用途 |
|---|---|
| `actual_input_tokens` / `actual_output_tokens` | 要聚合的量（可空，失败的 attempt 为 NULL） |
| `owner_id` / `space_id` | 按学生 / 按课程分组 |
| `provider_id` / `model_id` | 按模型分组 |
| `status` | `reserved`/`succeeded`/`failed`/`unknown`，只算 `succeeded` |
| `reserved_at` / `completed_at` | 时间窗口 |

**要做的四段：**

1. **store 聚合方法** — `tutor_runtime_store.py`。
   **现成写法可抄：**同文件 `_attempt_fold`（L1566 起）已经在
   `SELECT COUNT(*) … COALESCE(SUM(reserved_input_tokens),0) … FROM tutor_provider_attempts
   WHERE owner_id=? AND space_id=? …`，照它把 `actual_*` 加进去、把 `WHERE` 放宽到
   时间窗口、`GROUP BY space_id, model_id` 即可。
2. **desk 路由** — `python/src/desk_server/routes/study_routes.py`。
   **现成写法可抄：**同文件 `study_data_export`（`@router.get("/api/desk/study/data/export")`）
   那一小段的 `_desktop_data_service()` + `_http_error` 模式，五行。
   建议路径 `GET /api/desk/study/token-usage?window=week|month`。
3. **tauri command** — `tauri/src/study.rs` + `tauri/src/lib.rs` 注册。
   **现成写法可抄：**`cmd_study_data_export`（`study.rs` L691）就是同形状的
   `desk_json_request_structured(&app, Method::GET, "/api/desk/…", None)`。
4. **web 包装** — `web/src/chat/study/study-api.ts` 加一个 `cmdStudyTokenUsage()`。

**验收：** 只统计 `status='succeeded'`；NULL 不当 0 混入平均值；跨课程求和 = 各课程之和；
没有任何 attempt 时返回零而不是报错（新装用户第一次打开设置不能看到错误）。

**不要做：** 任何金额折算、任何按天的趋势图。

## B-2 `P1` 导入精读档位的默认值

**核过代码后的结论与规格初稿不同，先说清楚：**`read mode` 目前**根本不存在"用户默认值"
这个概念**。它是**模型每次自选的工具参数**——`hermes_core/tools/document/schemas.py`
里 `mode` 的 description 直接写给模型看（"DEFAULT to mode=auto … only escalate to the
much slower mode=precise/math when the user explicitly needs …"），
`reading.py::_docling_profile_for_mode`（L304）按每次调用的入参解析。

**因此这不是"把设置接上已有旋钮"，而是要先造旋钮。** 需要 Codex 决定并实现其中一种：

- **(a) 偏好注入 prompt**：把学生的默认档位写进工具描述或系统提示，模型仍可覆盖。
  改动小，但保证弱——模型可能不听。
- **(b) 硬上限**：在 `reading.py` 入口把超出默认档位的请求降级，除非调用方显式带
  `override=true`。保证强，但会让"我就是要精读这一页"变难。
- **推荐 (b) 但只作用于"导入"这一条路径**，对话里显式要求精读不受限。

**为什么值得做：**auto 是 pypdf 秒级，precise/math 是 CPU 推理，差一个数量级。
学生导一本 300 页教材撞上 precise 会以为程序卡死。见记忆 `docling-read-modes-and-perf`。

**前端已留位：** 设置 →「高级」tab，一个三档选择器。后端契约定了我再接。
