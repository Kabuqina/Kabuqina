场景视觉素材清单 · 第 0 步

风格基调页 · Style Tile

在画任何素材之前先定调。这一页锁定：桌面材质与主色、纸张白与纸纹强度、光照方向、阴影语言、圆角与线宽、铅笔/落墨字迹语言，以及与现有 kq-glass chrome 和 lucide 2px 图标线宽的接缝。本页 = light + dark 双主题基调 + 最终 token 表。通过后才开 P0 具体素材。

关键裁决 — B-5 笔记本原型里的 青绿强调色 #2f9e8f 属于风格漂移。真正的品牌盘（小娜杯 / 杯垫 / 聊天壳 / index.css --kq-color-* / kabuqinaBrandTokens）是 薰衣草墨 + 暖拿铁。桌面纸感保留，强调色统一收回品牌盘——素材不再各说各话。
