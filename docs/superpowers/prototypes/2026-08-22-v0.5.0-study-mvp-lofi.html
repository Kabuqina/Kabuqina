本轮按你的意见改了三处

  • 练 = 一道题。不再是空的练习壳，直接生成一道同知识核的题；下沿换成 问小娜（左）＋下一题（右）。「拍给我看」移进题目纸里，因为它属于这道题，不属于全局。
  • 扉页与材料拆开。现在是四个标签，slug 相应变成 notebook / cards / flyleaf / materials。
  • 改叫自习。「课程」→「自习主题」，模块名从学习改为自习，定位落到"学生自习时的辅导"。

仍在验证的合同

  • 学 / 练共享同一个知识核——切模式不换题目所属的那件事，题目纸上那行灰字标着它（R2）。
  • 转写合同可见——行序保留、看不清的明说不猜、置信度三档，给「重拍 / 升档 / 我来确认」三条路（§2.4）。
  • 讲评不是判分——三态确认固定，只有「确实做错」进错题草稿（R4）。
  • 两种可信度不混——「小娜讲解」与「你拍的书页」分开标（R1）。
  • 「拍一张」≠ 相机——选图 / 粘贴 / 拖入三条路，摄像头是检测到才出现的加成（R3）。
桌上还有一样东西这个屏幕里没有：纸。
S3「到纸上做」是产品故意不在场的一段。学模式把人推回纸上，练模式给完题也把人推回纸上， 屏幕只在他停笔（S4）和写完（S5）时才接手。
