## Outcome

Physically remove the owned Discord gateway surface: adapter, direct-send and
admin tools, Discord-only voice helpers, dependency, tests, active docs, import
paths, registries and fresh-runtime artifacts. Git history is the restoration
path.

The leaf must not delete user data. Old Discord credentials, profile folders,
thread/session records, cron jobs and home targets remain readable or explicitly
removable and continue to fail as `unsupported_delivery` under the C02 contract,
without adapter loading, network access or rerouting.

- removing generic media, TTS, attachment, transcription or voice-mode behavior

  `discord`

  trees

## Commit slices

1. **Retained-boundary preflight:** remove Discord mocks from otherwise generic
   tests and freeze media extraction/download, image/multi-image send, TTS media
   routing, voice command and platform-isolated voice-mode behavior using base
   or retained adapters.
2. **Mechanical leaf deletion:** delete the Discord adapter, tools, voice doctor,
   Discord-only tests/stubs and active Discord documentation route.
3. **Shared-spine cleanup:** remove Discord-only imports, branches, toolsets and
   CLI/config exposure without changing generic contracts or compatibility
   tombstones.
4. **Dependency/runtime closeout:** remove the direct dependency, regenerate the
   lockfile, update bundle/sync absence verification, build a fresh runtime and
   record evidence/sign-off.

Each slice receives an independent diff review. Dependency/lock and mechanical
source deletion are not squashed together during review.
