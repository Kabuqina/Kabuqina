# CTL-C07 · Legacy credential/job/home-channel upgrade JIT plan

> Status: **ACTIVE** · 2026-07-26 · owner: Codex C integrator

## Outcome

v0.4 的旧渠道数据在 v0.5 中保持可解释、可导出、可显式清理；它们不能启动 child、
扩展网络、成为发送目标或被静默改投。最终 installed-artifact upgrade 仍属于 CTL-G01/Q。

## Frozen safety contract

1. inventory 只返回 key 名、路径与计数，不经 IPC 暴露秘密值；
2. cleanup 必须先生成并读回验证一份本机 export，再携带该 export id 显式确认；
3. `.env` 仅改写有限 exact-key allowlist；`config.yaml`/`gateway.json`/
   `channel_directory.json` 只删除明确 removed platform 的结构化条目；
4. 只删除有限 exact files。绝不 `remove_dir_all`，绝不猜测 prefix 后递归删除 home/profile；
5. cron jobs 与 sessions 默认保留。旧 job 可列举、非投递字段可编辑、可删除；执行继续返回
   `unsupported_delivery`，不调用 adapter/network/model；
6. `QQ_HOME_CHANNEL{,_NAME}` 仅在用户执行 cleanup 时、canonical key 为空时显式复制到
   `QQBOT_HOME_CHANNEL{,_NAME}`。SMS/Feishu/WeCom 等绝不映射到 Email/微信/QQ；
7. 旧 Settings 深链显示 tombstone 和数据入口，不重定向到任何保留平台。

## Implementation slices

- Rust：旧数据 inventory/export/cleanup command、exact allowlists、verified export、结构化改写测试；
- Web：Advanced 中的旧渠道数据入口、先导出后清理交互、v0.4 Feishu/WeCom route tombstone；
- Core：未知/已删除 session origin 的安全反序列化与原样回写回归；复用既有 delivery contract；
- Evidence：记录测试、残留边界与 G01 owner upgrade handoff；本切片不运行 bundle。

## Exit

- destructive action 没有 verified export 或确认短语就失败；
- retained env/config/job/session 内容保持不变；
- removed env、removed config/channel-directory 条目与列举的 exact files 可显式清理；
- 旧 job/session 的 opaque identity 保留，且不存在 local/desktop fallback；
- Rust/Web/Core/Python 相关测试串行通过，C0 manifest audit 通过。
