## 0. 一句话

以「平台持 key 推理 + 订阅收费 + 境内已备案大模型」的形态为基线，把上架所需的行政资质拆成 **7 条并行工作流**；
**关键路径是生成式AI服务备案（约 6–8 个月）**，其次是双端 APP 备案与软著——最早启动、等待最长的先启动。

```
M0 立项 ──► 生成式AI服务备案（6–8 个月）──────────┐
           ├─ 软著（普通 3–6 个月 / 加急 20–30 工作日）┤
           ├─ 域名 + ICP 备案（2–4 周）→ APP 备案（20 工作日）┤──► 上架（M7）
           ├─ 苹果 / 安卓商店开发者账号（1–4 周）┤
           └─ 隐私政策 + 内容标识 + 等保（并行）─┘
```

## 1. 合规身份判断（先定身份，再定材料）

| 判断项 | 结论 | 依据 / 含义 |
|---|---|---|
| 谁是服务提供者 | **本公司** | 平台持 key 推理、用户订阅，公司是《生成式AI办法》下的「服务提供者」，承担全部义务（安全评估、内容审核、实名、标识、日志、投诉处理）。不是「调用方」也不是「上游模型方」 |
| 是否属备案范围 | **是** | 面向境内公众提供具有舆论属性/社会动员能力的生成式AI服务（智能对话）→ 需**算法备案** + **生成式AI服务备案**（两个独立事项） |
| 「备案」还是「登记」 | **大概率「备案」（按 6–8 个月排期）** | 仅调用第三方已备案基座且无二次开发可走「大模型登记」（3–4 个月）；我们有学习管线、导师 prompt、多轮教学逻辑 = 二次开发。**首周与属地网信办面谈确认** |
| 模型供应商 | **必须境内已备案大模型**（DeepSeek / 通义 / 豆包 / 智谱等直连官方 API） | 境外未备案模型面向境内公众 = 一票否决高风险；同时避免数据出境（PIPL/数据出境评估）。桌面端已有 DeepSeek 迁移基础（`docs/openrouter-to-deepseek-plan.md`），平板走官方 API 直连 |
| 教育类目 | **定位「AI 学习辅导工具」，避免「在线教育/学科培训」类目** | 培训类触发前置审批与双减红线；商店/备案类目选择直接决定前置审批材料。文案禁「保提分/包过/名师培训」承诺 |
| 是否经营性 | **是（订阅收费）→ 需评估 ICP 许可证** | 付费信息服务属经营性互联网信息服务；见 §5 |

### 1.1 「调用 API 也要备案」——判定的是服务关系，不是部署方式

备案义务挂在「**面向境内公众提供生成式AI服务**」这一事实行为上，不挂在「是否自部署模型」上。
持 key 与否决定了**用户与谁建立服务关系**：

| 模式 | 服务关系 | 谁是服务提供者 | 备案义务 |
|---|---|---|---|
| 桌面版 BYOK（用户自带 key） | 用户 ↔ 模型厂商（用户自己的账号） | 模型厂商；app 只是客户端工具 | app 侧不触发 |
| 平板版公司持 key（后台调 API） | 用户 ↔ **本公司**（订阅付费，用户不接触 key） | **本公司** | **触发**：算法备案 + 生成式AI服务备案（或登记） |

「调用已备案基座 API」不影响「要不要备案」，只影响「**备到哪一层**」与「**材料换什么**」：

- 纯调用、无二次开发 → **大模型登记**（3–4 个月）
- 有学习管线 / 导师 prompt 等应用层二次开发 → **上线备案**（6–8 个月）——大概率是我们的路径
- 材料差异：用 API 的不需要语料/训练侧材料，改为**与模型厂商的合作协议 + 对方算法备案编号**；安全评估报告、关键词库、测试题集、测试账号照旧
- **算法备案独立存在**：只要服务有舆论属性/社会动员能力就要做（beian.cac.gov.cn），与调用方式无关

商店侧不是理论问题而是执行问题：小米/华为 2023-08 起就把「算法备案编号或审批中截图」列为上架材料，
「清朗·整治AI应用乱象」持续整治应备未备——「不备案」在 0.6.0 上架路径上走不通。

**「备案完成前先 BYOK 上架过渡」不成立**：
① 商店按 AI/深度合成**类目**核验材料、不区分 key 归谁——BYOK 应用照样要算法备案（或审批中截图）+ 第三方模型协议；
苹果中国区本就强制 APP 备案号（与 key 模式无关），AI 对话类实务还会核验合规材料。
② BYOK 与 0.6.0 架构冲突：云端学习管线/拍照批改的推理必须在服务端——key 在服务端 = 公司仍是服务提供者；
key 在设备端 = 云端管线失效、学习数据上云的设计也作废。
③ 订阅制 + 用户自带 key 商业逻辑冲突（用户付费买什么）。
备案完成前的市场验证走 **TestFlight 外部测试（≤1 万用户）/ 私域 APK**——法律义务（标识、审核、实名）不因渠道豁免，
但商店 gate 不卡；正式上架等备案（或登记）完成。

**BYOK 测试阶段（不进商店）生成式AI服务备案可暂缓**：严格 BYOK 下服务关系在用户与模型厂商之间
（用户自己的 key/账号，模型厂商已就其 API 服务完成备案），公司只是客户端工具 → 不是服务提供者 → 不触发。
**但条件严**：不送 key、不共用额度、不垫付 token——任何「公司给免费额度/试用 token」的形态都使公司成为服务提供者，
生成式AI备案义务随即成立。算法备案在测试阶段仍做（商店硬材料 + 应备未备整治的风险对冲）。
测试阶段不可豁免的底线：内容标识（GB 45438-2025 已生效）、输入输出内容审核、隐私政策与投诉渠道。

## 3. 工作流 A：主体与账号前置（第一周可完成大半）

- [ ] **营业执照**（大陆注册企业；确认经营范围含软件开发/信息技术服务）
- [ ] 对公账户 + 网银 U 盾（商店实名、苹果收款、ICP 许可证都需要）
- [ ] 法人/负责人身份证件、联系方式
- [ ] **域名 1 个**（品牌域或与 APP 名一致；隐私政策/用户协议落地页 + 后续算法备案公示用）
- [ ] **境内云账号**（阿里云或腾讯云：域名 ICP 备案接入商 + 托管后端 + 隐私政策静态页）
- [ ] **D-U-N-S 邓白氏编码**（苹果企业账号必需；通过苹果申请免费，1–2 周）
- [ ] 企业邮箱、客服邮箱/电话（投诉举报渠道要求）

## 4. 工作流 B：软著（最先启动、最快下证、解锁所有安卓商店）

- 材料：登记申请表（盖章）、源代码**前 30 页 + 后 30 页**（每页 ≥50 行）、操作说明书、营业执照副本。
  **2026 年起 AI 辅助开发需附《AI 合规及原创性声明》**（我们的代码含 AI 辅助，提前准备）。
- 周期：官方受理后 60 个工作日内（2026 严审后实务 3–6 个月）；**加急 20–30 工作日**（代理费约 500–1500 元）。
- 策略：**M0 立即按普通流程提交**；若 0.6.0 上架时间点临近仍未下证，走加急通道兜底。
- 数量与命名：**1 件**即可（如「卡布奇娜学习助手软件」），名称须与**商店上架名完全一致**（苹果校验 APP 名与备案名一致、商店校验软著名与 APP 名）。
- 覆盖：安卓各商店三选一材料（软著 / 电子版权证书 / 软著认证证书）中以软著最通用；iOS 不强制。

## 5. 工作流 C：ICP / APP 备案（双端分别办理）

| 事项 | 归口 | 周期 | 说明 |
|---|---|---|---|
| 域名 ICP 备案（非经营性） | 接入商 → 属地管局 | 2–4 周 | 隐私政策/用户协议落地页必需；**可立即启动** |
| **APP 备案（Android）** | 工信部（经云接入商） | 20 个工作日 | 材料：营业执照、负责人、**包名 + 签名公钥 + 签名 MD5**、服务器 IP |
| **APP 备案（iOS）** | 工信部（经云接入商） | 20 个工作日 | 材料：**Bundle ID + 证书 SHA-1**；与安卓分别备案 |
| **ICP 许可证（经营性，决策点）** | 属地通信管理局 | 2–3 个月 | 订阅收费 → 经营性信息服务；要求注册资本 ≥100 万、专业人员社保。**华为上架还要求许可证业务范围含「国内多方通信服务业务」**（见 §9）。建议启动办理；若预算/条件不允许，先与管局和商店确认豁免口径 |

时序要点：APP 备案必须等**包名/Bundle ID/签名确定**（M4 前后），但材料清单可以提前备好；
域名备案、ICP 许可证申请不依赖代码，**立即并行启动**。

## 6. 工作流 D：算法备案 + 生成式AI服务备案（**关键路径，M0 第一周启动**）

> 分步操作手册（两套流程 + 材料清单 + 并行时间线 + 本周启动清单）：`docs/ai-filing-process.md`

### 6.1 算法备案（独立事项）
- 系统：互联网信息服务算法备案系统（beian.cac.gov.cn）。
- 范围：智能对话 = 文本生成类深度合成算法，**1 项**；若后续加语音/图像生成需逐类增加（0.6.0 暂只文本）。
- 材料含：算法安全自评估报告、安全评估报告、等保测评报告（实务常见要求）。

### 6.2 生成式AI服务备案（上线备案）
- 路径：**预约属地网信办面谈**（区→市→省→中央网信办逐级审核），全程 **6–8 个月**（含 4–6 轮修改）。
- 核心材料（均需盖章）：
  - 上线备案表（服务范围、算力、语料来源、算法架构）
  - **安全评估报告（30–100 页）**：语料安全、生成内容安全、拒答率、数据隐私；**敏感问题拒答率 ≥95%、人工审核率 ≥10%**
  - 拦截关键词列表（≥1 万词，覆盖 17 类风险，每月更新）
  - 评估测试题集（生成题 ≥2000、拒答题 ≥500、非拒答题 ≥500）
  - 模型服务协议 = 用户协议 + 隐私政策（备案与商店复用同一套）
  - **测试账号**（含最高权限账号，供网信办技术测试）
- 若面谈后判定可走「登记」路径：3–4 个月，材料大减。
- 等保：面向公众 AI 服务按**等保二级起步、三级常见**；测评 + 整改约 2–3 个月，**与备案材料联动**，定级后尽快启动测评。
- 收尾：备案号公示后写入产品（网信办公示 + 商店审核用），配合常态化安全测试。

## 7. 工作流 E：隐私政策 + 用户协议 + 合规文案（技术可并行的行政产出）

- **隐私政策**（PIPL 全要素）：处理者、目的方式范围、保存期限、用户权利、联系方式；**第三方共享清单必须列明 LLM 模型供应商**（用户输入/学习数据发送给模型 API）、推送厂商、商店/支付 SDK。
- **双清单独立页面**：收集个人信息清单 + 与第三方共享清单（工信部 App 合规检查要求）。
- **用户协议**：含禁止事项（作弊/代考用途）、免责声明、数据使用、投诉机制（7 个工作日反馈）。
- **未成年人条款**：实名分级；<14 岁需监护人同意；防沉迷提醒（生成式AI办法明确要求）。
- 落地页：域名 + ICP 备案后挂隐私政策/用户协议/双清单 URL（**苹果与安卓商店均要求可访问 URL**）。
- 注册前可见（注册流程首屏可读），App 内 Settings 常驻入口。
- 预留预算做一次第三方 App 隐私合规检测（约 0.5–2 万/次），上架前整改完毕。

## 8. 工作流 F：苹果开发者（企业账号 + 中国区上架）

| 项 | 说明 |
|---|---|

| 审核要点 | AI 生成内容：过滤机制、举报渠道、标识实现说明；教育类：未成年数据保护说明；隐私政策 URL 可访问 |
| 计费 | 订阅走 App Store IAP；**申请 Apple Small Business Program 降至 15% 抽成**（年营收 <100 万美元） |
| 周期 | 首次提审预留 2–4 周（含拒审往返）；AI 类应用建议先提交预审材料沟通 |

## 9. 工作流 G：国内安卓商店开发者账号（小米首发，其余批次铺开）

**账号清单**（平板相关）：小米（首发）、华为、OPPO、vivo、荣耀、应用宝（腾讯）、360、三星（Galaxy Tab）、联想（可选）。

**共性材料**（每家一份，随用随交）：
- 企业实名认证：营业执照、法人身份证、对公账户验证
- **软著 / 电子版权证书 / 软著认证证书（三选一）** ← §4
- **APP 备案号** ← §5；**隐私政策 + 用户协议 URL** ← §7
- 应用安全自测/检测报告（各家格式不同，可用第三方报告通用）

**AI/深度合成类专属要求（2025–2026 收紧后的实际口径）**：

| 商店 | 特有要求 |
|---|---|
| 小米 | 算法备案编号（或「审批中」截图）＋ 安全评估报告 + 全国互联网安全管理服务平台通过截图 ＋ **第三方模型厂商算法备案截图 + 合作协议**（协议含算法名称/备案编号）＋ **内容标识合规承诺函**（2025-09 起） |
| 华为 | 算法备案 + 安全评估报告 + 网安平台截图 + **增值电信业务经营许可证（业务范围含「国内多方通信服务业务」）**——成本高、办理难，**决策点**：若不可行则华为后置，先小米+苹果+其余商店 |

**执行建议**：
- 与各家商店**提前建联 BD/运营通道**（AI 应用审核口径变动快，官方指引落后于实际执行）；
- 分批上架而非同日全量：小米 → 苹果 → OPPO/vivo/荣耀/应用宝 → 华为（视资质）；
- 每家审核预留 1–3 周，材料模板化复用。

## 14. 待确认决策点（不阻塞启动，但影响材料口径）

1. **备案 vs 登记**：首周属地网信办面谈后定（§6）。
2. **ICP 许可证是否办理**：订阅收费 + 华为要求双因素，倾向办（§5/§9）。
3. **华为首发与否**：视「国内多方通信」许可证办理难度（§9）。
4. **商店类目**：选「工具/学习工具」类目，规避教育前置审批（§1）。
5. **未成年人模式深度**：先做实名分级 + 防沉迷提醒；未成年人模式指南若商店强校验再补（§7/§10）。
6. **等保等级**：与属地网信办/测评机构确认二级还是三级（§6）。
