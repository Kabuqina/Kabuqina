## Scope

The owner requested C04 as one combined development batch rather than five
separate leaf bundle cycles. The implementation therefore removes the C04
families together while preserving the original ownership boundaries:

- C04a: SMS/Twilio;
- C04b: Slack, Signal, Matrix and Mattermost;
- C04c: BlueBubbles, Home Assistant and Yuanbao;
- C04d: gateway Webhook and API Server;
- C04e: bundled IRC and Teams platform plugins.

The retained external adapters are exactly Weixin, QQBot, DingTalk, Telegram,
WhatsApp and Email.

## Required changes

1. Delete the owned adapters, platform-only tools, bundled plugin source,
   platform-only tests and dedicated active documentation.
2. Remove platform-exclusive extras and regenerate `uv.lock`.
3. Make adapter creation, config loading, toolsets, cron delivery, channel
   discovery and direct-send routing fixed retained allowlists.
4. Reject dynamic platform plugin registration and override. Existing
   non-platform plugins may still load, but cannot create a product platform.
5. Keep removed enum/config values only as compatibility tokens: they may be
   read and ignored, but cannot enable an adapter, expand network trust or
   reroute delivery.
6. Extend source/runtime pruning verification and refresh the C0 generated
   ledgers.

## Verification

- affected Core tests, including retained positive and removed negative
  contracts;
- Python build/runtime/profile verifier tests;
- `compileall` and `git diff --check`;
- C0 generated-ledger refresh followed by a no-refresh audit;
- source and dependency absence scans.

This branch does not run `python/build_bundle.ps1`. Per the owner-approved
combined Review process, fresh integrated runtime proof remains a single
C05/G01 consumer check, not a repeated C04 leaf-development Gate.

## Non-goals

- deleting persisted credentials, sessions, jobs or home-channel data (C07);
- final shared license/SBOM and integrated bundle closeout (C05/G01);
- changing or proving retained adapter release readiness (C06);
- merging C04 to `main` without review.

## Rollback

Revert the combined C04 implementation commit. No user data migration or
destructive cleanup is performed by this slice.
