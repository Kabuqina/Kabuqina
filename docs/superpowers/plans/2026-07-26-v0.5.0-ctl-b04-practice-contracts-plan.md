## 2. 冻结合同

### 2.1 Grader truth 与 provenance

每个 materialized active question 固定一个 `PracticeGraderProvenanceV1`：

```json
{
  "schema_version": 1,
  "source_kind": "activated_quiz_item",
  "artifact_id": "...",
  "artifact_version": 1,
  "item_id": "...",
  "grader_kind": "choice_exact|boolean_exact|short_answer_exact|code_sandbox|code_transcribe|derivation",
  "rubric_sha256": "64 lowercase hex",
  "policy_version": "practice-grader-v1"
}
```

`rubric_sha256` 只 hash deterministic grader 所消费的 canonical hidden truth；不含 learner response、
hint、模型建议或 secret。公开 submit result 可以返回 provenance/hash，但 questions route 不能返回
hidden truth。

结果 `outcome` 只允许：

- `correct` / `incorrect`：仅 deterministic grader 可产生，允许后续 L-3 branch；
- `timeout`：sandbox 超时，禁止当 wrong answer；
- `sandbox_failure`：runner unavailable/termination/invalid execution，禁止当 wrong answer；
- `ungradable`：unsupported language、缺失/不可判定 derivation component 等，禁止 pass/fail。

只要 derivation 有 required cloze component 无法可靠评分，新的 branchable `outcome` 必须 fail
closed 为 `ungradable`。为兼容 v0.4，既有 `score/correct` 字段仍可表达“已判 component 的 partial
score”，但 L-3/P-2 禁止把这些 legacy partial 字段当 branch predicate；UI 必须同时显示
`ungraded_steps`，不能把 partial score 文案写成整题通过。

### 2.2 Activated hint ladder

question 可选：

```json
"hint_ladder": {
  "schema_version": 1,
  "direction": "概念方向",
  "next_step": "定位下一步或错误",
  "scaffold": "局部脚手架",
  "full_solution": "显式完整解答"
}
```

- 至少一个非空 level；每项有 codepoint/UTF-8 总量上限；unknown field 拒绝。
- draft 可以由模型生成，但只有 user-activated quiz materialize 后可消费。
- service 不从 `answer/accepted/reference/test_code/target_code/expr_py` 动态拼 hint；缺少所请求层级就
  返回 `hint_unavailable`，避免误泄漏。
- 层级可任意跳转或直接请求 `full_solution`；不强制解锁，不自动升级。
- 每 item 最多 8 次不同 hint request；idempotent replay 不重复计数。
- response 只含本次 level/content、ordinal、zero-provider budget summary。activity detail 只保存 level、
  request fingerprint、content hash 和 ordinal，不保存 hint 文本。

### 2.3 Hint identity/idempotency

`PracticeHintRequestV1` exact fields：`schema_version=1`、`artifact_id`、`item_id`、
`idempotency_key`、`level`。owner/space 由 host context 注入。canonical fingerprint 排除
idempotency key；同 owner/space + stable derived activity id：

- same fingerprint → 返回同一 activity/result，不新增 evidence；
- different fingerprint → `LearningConflictError` / HTTP 409；
- concurrent same request 只有一个 insert winner。

LearningStore 新增通用 `insert_activity_once`，复用 v1 PK 与 coordination write guard，不改变 schema、
export/import 或 owner delete 语义。

### 2.4 Level ⑤ evaluation draft boundary

question 可选 `explanation_rubric`：`schema_version=1`、1..8 个 exact criteria；每项有稳定
`criterion_id`、bounded `description`、bounded tags。rubric 只在 quiz activation 后 pin 为 canonical
hash。

learner explanation request ≤8,000 codepoints、canonical request ≤32 KiB，必须绑定 active
artifact/item 与 pinned rubric hash。typed semantic result只允许：

- per-criterion `addressed|gap|uncertain`；
- bounded observations/suggestions/tags；
- source/rubric provenance 与 numeric usage summary。

schema 不存在 `passed/correct/mastery/score/branch`。service 最多调用 injected evaluator 一次，无
应用 retry/fallback；exception、None、timeout 或 invalid typed result → `pending` 且不创建 draft。
合法 result 只能经 OutputWriter 创建 `evaluation` draft，source refs 绑定 item/rubric/evidence；用户仍
通过既有 activate/reject 决定是否进入 active projection。

B04 不提供 production network evaluator，不调用 `call_llm()` 或旧 semantic reviewer。P-2 接线前
必须另有 write-ahead budget/resume contract；因此 B04 的 cost 真值为 hint=0，fake evaluator
physical calls ≤1，不能把 test seam 冒充 production readiness。

## 6. Rollback 与 stop rules

- commit 边界可逐项 revert；不 reset main，不触碰用户 A-track dirty files。
- old active quiz 不迁移；无 hint/rubric 即诚实 unavailable/pending，existing grading 仍工作。
- rollback 后新增 activity rows 是普通 bounded evidence，可随 owner export/delete；没有新 DB schema。

立即停止并报告，如果：

- 必须让模型或 semantic reviewer直接写 `correct/passed/branch/mastery`；
- 必须从 hidden answer/reference/test code 自动生成低层 hint；
- production evaluator 需要 `call_llm()` retry/fallback 或没有 write-ahead budget 才能接线；
- 必须改 B02 Tutor runtime schema、普通 Agent graph、Gateway 或 Web/A-track shared hot files；
- 无法区分 timeout/sandbox failure/ungradable 与 wrong answer；
- hint idempotency 需要绕过 owner/space coordination 或修改 schema；
- old quiz/bundle/import 无法保持向后兼容。
