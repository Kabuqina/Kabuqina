## 2. 冻结行为

### 2.1 L-2 graph 与 deterministic branch

```text
start
  validate_context
  explain_bounded_unit        # provider attempt 1
  handoff_to_learner
  learner_control_check_1     # continue | explain_again

resume(answer=continue)
  completed(participation_only)       # zero provider call

resume(answer=explain_again)
  remediate_once              # provider attempt 2, only once
  learner_control_check_2     # continue only

resume(answer=continue)
  completed(participation_only)       # zero provider call
```

- check option 是 host template，不由模型生成；模型只生成 bounded explanation/remediate prose。
- invalid option 保持原 check、revision + 1、零模型调用；check 2 伪造 `explain_again` 也属 invalid。
- free-text/step 不升级为 correctness；L-2 不调用 grader，不推断 pass/fail。
- provider failure/timeout/invalid typed output 必须持久化 frozen blocked code，不能回退普通 Chat。

### 2.2 Provider port 与恢复

- `TutorProviderPlanV1` 在 create 时从当前 desktop runtime 本地解析成一个 provider/model/api_mode/
  endpoint identity；checkpoint 保存公开 plan，run 保存 hash，均不含 key。
- `provider=auto` 只在 create 时解析；recover 根据已保存 plan 重新绑定该固定 provider 的凭据并
  核对 hash，不重新 auto-detect，不换 model/api_mode/endpoint。
- production 只支持 frozen `chat_completions` 与 `anthropic_messages` 单次 transport；其他 mode 在
  create 前返回 not-ready，不创建 run。
- OpenAI/Anthropic SDK client factory 显式 `max_retries=0`，无 credential pool rotation、无 provider
  fallback、无应用层循环。一次 `execute_once()` 最多产生一个 HTTP request。
- write-ahead reservation commit 成功后才可发 HTTP；crash 遗留 `reserved` 由 B02 reconciliation
  标 `unknown`，不退款、不重发该 segment。
- start 最多一次 attempt，第一次 `explain_again` 最多再一次；其他 resume 均为零 attempt。

### 2.3 预算与 deadline

- start segment graph nodes ≤6，resume ≤4，activity ≤14；learner checks ≤2。
- attempt input/output/wall reservation ≤16,384 / 2,048 / 35,000 ms；activity总量沿用 B02 cap。
- active segment monotonic deadline ≤45 s，activity active elapsed ≤120 s；等待 learner 不计时。
- provider 前预留 10 s finalize，`timeout=min(35s, segment_remaining-10s,
  activity_remaining-10s)`；remaining ≤10 s 时不 reservation，直接 blocked budget exhausted。
- 每个持久化 node/settlement 都累计 active elapsed；异常不能借由 restart 清零。

## 4. 实施任务与 commit 边界

- graph state 只含可序列化数据；client/store/callback 只经 runtime context。

**Commit：** `feat(tutor): add deterministic L2 graph contract`

### Task 2 · Single-attempt provider port

- 固定 plan/hash、typed request/result、bounded JSON/prose parsing。
- dedicated OpenAI/Anthropic client factory `max_retries=0`；测试物理请求计数、timeout、invalid output、
  unsupported mode、credential missing 与 fixed-plan restart rebind。
- tokenizer 未知时用 UTF-8 bytes 保守 reservation；结果 usage 只观测、不退款。

**Commit：** `feat(tutor): add hard-budget provider port`

### Task 3 · Engine 与 B02 lifecycle 接线

- start：validate → resolve plan → create checkpoint → claim → reserve → execute → settle → interrupt。
- resume answer/recover：CAS claim、deterministic branch、必要时第二 attempt；cancel 与 concurrent claim 沿用 B02。
- node/active elapsed 持久化、blocked/terminal atomic commit；不直接访问 runtime private tables。
- idempotent start 同 payload 返回既有 snapshot，异 payload conflict；终态 resume immutable。

**Commit：** `feat(tutor): execute resumable L2 activities`

### Task 4 · Desktop wiring 与 readiness

- desk 构造 provider resolver + engine + service；owner 仍由 host 注入。
- 打开既有 start/resume routes；保留 get/list/cancel 与结构化错误 taxonomy。
- capability 从真实 import/provider contract 计算 readiness；没有 credentials 时 start 503 且零 row。
- Rust bridge 无 wire 变化则只补 focused regression，不制造无意义 diff。

**Commit：** `feat(desktop): activate minimal Tutor runtime`

### Task 5 · Recovery/E2E 与 evidence

- 真实 SQLite + fresh process E2E：start/interrupt/restart/recover/answer/cancel。
- reservation crash-before/after-call unknown、不重发、attempt 总数 ≤2；并发 resume 只有一个 claim。
- ordinary Chat graph differential/focused suite零变化；bundle imports 包含五个 Tutor graph 模块。

## 6. Rollback、兼容与 stop rules

- 合入前按上述 commit 边界 revert；不 reset/覆盖 main 或其他 worktree。
- B03 不迁移 DB、不改 public wire；回滚后 B02 start/resume 恢复 503 gate，已有 B02 数据仍可
  get/list/cancel/restore。
- 已发出 provider request 的 reservation 永不退款；rollback/recovery 不允许删除 attempt history 来
  重新取得预算。
- provider plan/hash mismatch、未知 graph/checkpoint version、terminal invariant 不一致均 fail closed。

以下任一发生立即停止并报告：

- 必须修改 B02 DB schema/quota/BundleV2 才能实现 graph；
- 无法在物理 request 前 durable reservation，或 SDK/transport 无法关闭内部 retry；
- recover 必须重新 auto-detect/fallback 才能继续；
- 需要模型决定 correctness/pass/fail，或必须扩大 L-2 超出 participation-only；
- 需要修改普通 Agent graph/run loop、Gateway Tutor、Web scene 或 C 轨 shared spine；
- active deadline/attempt/node cap 不能跨 crash 保守维持；
- canonical Windows wrapper、fresh-process recovery 或 bundle source import 无法复现。
