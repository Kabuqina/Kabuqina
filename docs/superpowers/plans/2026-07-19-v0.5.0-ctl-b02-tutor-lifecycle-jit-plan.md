## 2. 冻结边界

### 2.1 本卡必须实现

1. `learning.db` schema 保持 v1；新建 `tutor_runtime.db` 与
   `learning_coordination.db`，两者 reader 对 unknown-newer fail closed。
2. 所有 `LearningStore` public read/write、Tutor repository read/write 与 outbox projection
   通过同一 `LearningOperationCoordinator`。
3. operation guard 固定锁序 `coordination → learning → runtime`；ordinary caller 无法伪造
   `OperationLease`。
4. run/checkpoint/attempt/outbox transaction、四元 PK、scoped idempotency fingerprint、CAS、
   terminal numeric summary 与 retention 严格按 B01 §3–§7。
5. BundleV2 使用统一 UTF-8 serialized-byte 口径和 24 MiB outer cap；完整 import 与
   `tutor_runtime_merge` 都是 all-or-nothing。
6. public activity API 已注册但 B02 没有 graph/provider：start/resume 返回
   `study_activity_not_ready` 且零 row/零模型调用；get/list 可读已恢复数据，cancel 可终止已有
   nonterminal fixture/imported run。B03 接入 engine 后才打开 start/resume。
7. capability `student-tutor-runtime` 在 B02 保持 `candidate/not_ready`，不能用“表已存在”冒充
   Tutor 可用。

### 2.2 明确不做

- 不添加 `TutorGraphEngine`、provider resolver/client、prompt、learner check UI 或真实 start。
- 不修改普通 `TurnState/build_agent_graph/GraphEngine`、`run_agent.py`、tool loop。
- 不开放 Gateway Tutor，不改 gateway adapter/command surface；Gateway 只参与共享 store fence 测试。
- 不改 Web scene、Study visual、Practice/Whiteboard、kq-kp v2/H4。
- 不改 `learning.db` v1 表/版本，不把 operation fence 放进 overlay 或 desk process memory。
- 不把真实 v0.4 installer/updater Gate 降格成“当前 source 改版本号”测试。

## 3. 目标模块与依赖方向

```text
desk / gateway / cron LearningStore callers
  -> LearningOperationCoordinator        learning_coordination.db
       -> guarded LearningStore          learning.db v1 unchanged
```

## 5. 实施任务与 commit 边界

每个任务先写 failing behavior tests，再实现最小代码；任务结束单独 commit。schema、业务接线、
bridge/evidence 不混进同一大提交。

### Task 1 · Contracts 与 in-memory port fake

**目标：** 在任何 SQLite/HTTP 代码前冻结 wire/state/error validators。

- 定义 `LearningActivityKeyV1`、start/resume/cancel/snapshot/interrupt、canonical request
  fingerprint、size/ID/forbidden-field validators。
- 定义 checkpoint/repository/coordinator protocols 与 in-memory fake contract suite。
- 覆盖四元 identity、kind-required route key、同 idempotency key 同/异 payload、unknown schema、
  terminal immutable、合法/非法 lifecycle transition。

**Commit：** `feat(learning): add Tutor lifecycle contracts`

### Task 2 · Cross-process operation coordinator

**目标：** 独立完成 `learning_coordination.db`，尚不接业务 store。

- schema v1、unknown-newer rejection、WAL/busy retry/secure-delete/ACL。
- `begin_read/begin_write/begin_operation/advance/finish/recover`；opaque lease 绑定
  operation/owner/space/kind。
- Windows `multiprocessing` spawn tests：ordinary reader/writer 与 owner/space fence 互斥、不同
  scope 行为、crash 后 fence/journal 仍在、伪造 lease 拒绝、锁超时为 bounded typed error。

**Commit：** `feat(learning): add cross-process operation coordinator`

### Task 3 · Guard existing LearningStore

**目标：** 让所有共享 learning writer/reader 真正参与 coordinator。

- constructor 从 resolved `db_path.parent` 派生 coordinator；test/custom DB 同规则。
- `_execute_write(owner_id, space_id, fn, lease=None)` 与 central read wrapper；逐一迁移所有 public
  create/set/update/activity/migration/import/delete 与 get/list/export。
- owner-wide 方法使用 `space_id=''`；exact-space 方法同时受 owner fence 限制。
- outbox projection 必须走 guarded `insert_activity`；禁止 production raw writer。
- integration tests 使用真实 desk/Gateway/cron constructor shape 和两个 spawned processes，证明
  delete/import fence 中 Gateway write 返回 `learning_operation_in_progress`，fence 后可安全重试。

**Commit：** `feat(learning): enforce shared operation guards`

### Task 4 · Tutor runtime SQLite adapter

**目标：** 实现 B01 §6.2–§7 的 runtime truth，不接 graph。

- 建表、PK/unique/check constraints、indexes、quotas、256 KiB checkpoint cap。
- create/load/save/clear/claim/cancel/interrupted/reconcile/terminal；每个复合更新单 transaction + CAS。
- request fingerprint mismatch 409；duplicate same payload 返回同 snapshot。
- provider reservation 表与 terminal numeric fold 只实现 persistence contract，不发送 HTTP。
- terminal transaction 清 checkpoint、写 bounded run summary + stable outbox event。
- ACL/WAL/busy/two-process/unknown-newer/secure-delete tests。

**Commit：** `feat(learning): add Tutor runtime persistence`

### Task 5 · Composite delete、BundleV2 与 downgrade restore

**目标：** 关闭跨两个业务 DB 的 owner/space data operation。

- `CompositeLearningDataService` 的 phased delete/import/recovery，全部使用 matching operation lease。
- BundleV2 canonical hash/count、16 MiB learning subsection、6 MiB runtime subsection、24 MiB outer、
  checkpoint/owner/terminal/outbox quotas。
- `replace_empty_owner` 在 fence 内复查两库为空；phase crash cleanup 只删除 rollback manifest keys。
- `tutor_runtime_merge` 不覆盖 learning rows；同 fingerprint 幂等、异 fingerprint 整批 conflict、
  missing source 进入 recovery-visible `blocked(source_missing)`。
- stable outbox `projection_event_id` 查重；restore 重放不复制 terminal event。
- v1 bundle import 保持兼容；v2 export→delete→import、near-cap、oversize zero-write tests。
- prepare-downgrade 两阶段 service：先生成并回读验证 bundle/hash，再在 hash 未漂移时取得 owner
  fence并清 runtime DB；任何验证/落盘失败都不删除数据。

**Commit：** `feat(study): add composite Tutor data operations`

### Task 6 · Desk routes 与 capability readiness

**目标：** 暴露 L-1 wire，但不制造假 Tutor runtime。

- 注册 `/api/desk/study/activity-runs` start/get/list/resume/cancel routes 与结构化错误映射。
- B02 start/resume readiness gate 返回 503/零 row；get/list/cancel 用 repository 真值。
- 扩展 existing data export/import/delete 到 BundleV2 + mode；新增 prepare-downgrade service routes。
- public request 忽略/拒绝 owner；desktop owner/space/kind 全路径测试。
- capability `student-tutor-runtime` lifecycle=`candidate`，pipeline 全部 not ready；普通 learning
  foundation capability零变化。

**Commit：** `feat(desktop): expose Tutor lifecycle candidate APIs`

### Task 7 · Tauri bridge 与本地备份文件

**目标：** Rust 只做代理、路径/大小与安全文件流程。

- 增加 `cmd_study_activity_start/get/list/resume/cancel` 并注册。
- import file cap 从 10 MiB 统一为 24 MiB；接受 v1/v2，仍要求 absolute `.json` regular file、UTF-8、
  合法 JSON。
- prepare-downgrade command 使用同目录 temp file → flush/fsync → atomic replace → readback parse/hash；
  只有 Python 再次确认 current bundle hash 未漂移后才 commit runtime deletion。
- Rust tests：invalid path/symlink-or-nonfile/oversize/hash drift/write failure/readback failure 均零删除；
  v1 10–16 MiB 与 v2 near-24 MiB 边界。

**Commit：** `feat(tauri): bridge Tutor lifecycle and safe backup`

### Task 8 · Recovery、真实旧版本与 bundle evidence

**目标：** 用执行证据关闭 B02，而不是只靠 unit fake。

- spawned desk/Gateway writer race + crash phase matrix；restart 接管 operation。
- 真实 v0.4 source runtime `f6229d96` 验证它不打开/修改 runtime/coordination DB；owner delete 留下
  Tutor DB 记录为 expected red characterization。
- 对官方 v0.4 artifact hash做 file preflight；installer/updater downgrade 阻断与最终候选安装归
  `CTL-G01/Q-3`，B02 不伪造 release PASS。
- prepare 后在 v0.4 新增 learning rows，再回 v0.5 `tutor_runtime_merge`；新行保持、restore 幂等、
  conflict zero-write。
- bundled CPython import new core/routes；bundle verifier、focused Rust/Python/core suites。

**Commit：** `test(b): close CTL-B02 lifecycle evidence`

## 7. Rollback、兼容与数据安全

- B02 合入前：按 commit 边界 revert；不 reset/覆盖其他 worktree。
- `learning.db` 保持 schema v1，v0.4 继续读取既有数据；新 DB 是 additive 文件。
- B02 capability 仍 candidate，因此 rollback 不需要 Web/API consumer migration。
- 已创建 Tutor runtime 数据后不得建议直接 v0.4 owner delete；必须使用 verified BundleV2 +
  prepare-downgrade/runtime-only restore runbook。
- composite operation 未完成时 fence/journal 保留；rollback/recovery 先完成或安全清理 operation，
  不能直接删 coordination DB 解锁。
- 任何 schema/cap/identity/public wire 变化先回到 B01/`DECISIONS.md` 复审；实现者不得暗改。

## 8. Stop rules

以下任一发生立即停止 B02 并报告，不用 fallback 掩盖：

- 发现 production `learning.db` raw writer 无法纳入 coordinator；
- 需要升级 `learning.db` 到 v2、把 fence 放入 overlay、或依赖两个 Python 进程共享内存；
- 跨库 crash cleanup 可能删除 operation 开始后的新数据；
- BundleV2/prepare-downgrade 在备份未验证时可能删除 runtime DB；
- start/resume 需要提前接 LLM/graph，或 capability 必须假报 ready 才能测试；
- 需要修改普通 Agent graph/run loop、Gateway Tutor 或 Web scene；
- v1 import、ordinary Study/Gateway/cron 行为回归，或 24 MiB 各层口径不一致；
- canonical wrapper、Rust/Python tests 或 bundled import 无法在 hermetic Windows 环境复现。

## 9. Review handoff

B02 进入 `REVIEW` 时至少需要以下 reviewer：

- DB/schema：三 DB、CAS、lease、WAL/ACL、quota/retention；
- Core/Gateway/cron：所有共享 store caller 真正受 fence 约束，普通行为不变；
- Security/privacy：identity、idempotency、delete/import/restore、redaction；
- Rust/bundle/release：24 MiB、safe backup、v1 compatibility、v0.4 characterization；
- B03 consumer：repository/wire 足以接 graph，不需猜 private SQLite state。

非作者 reviewer 对 evidence commit 签字前，B02 不得 `DONE`，B03 不得启动。
