### Why the two fallthroughs are unreachable

Both live protocols are `chat_completions` and `anthropic_messages`. Their
`normalize_response()` implementations always return `NormalizedResponse` for a
valid response. In the `finish_reason == "length"` branch:

1. a non-tool normalized response enters the text continuation branch and
   either restarts or returns at 10485;
2. a tool-call normalized response enters the tool truncation branch and either
   retries or returns at 10513;
3. therefore control cannot reach 10522 for either supported protocol.

A fake transport normalizer returning `None` would violate the production port
contract and would characterize a test double, not Kabuqina. If a third protocol
or optional normalized response is introduced, this classification must be
revisited before merge.

## Harness changes required by Task 2

The golden schema needs explicit, reviewable preconditions rather than hidden
test patches:

```json
{
  "assumed_retry_counts": {
    "api_max_retries": 3,
    "max_compression_attempts": 3,
    "text_continuation_attempts": 3,
    "truncated_tool_call_retries": 1,
    "incomplete_scratchpad_retries": 2,
    "unknown_tool_retries": 3
  },
  "transport_turns": [
    {
      "raise": {
        "type": "api_error",
        "status_code": 413,
        "message": "request payload too large"
      }
    }
  ],
  "preconditions": {
    "context_length": 200000,
    "compressed_history_sequence": []
  }
}
```

Exact keys may change during implementation, but these concepts may not be
implicit. `test_retry_contract.py` must compare fixture assumptions with the
current production defaults and hard-coded branch limits. A changed retry count
must fail with a targeted contract message before a transcript runs out of
scripted turns.

The harness may stub the compressor integration boundary, as it already does for
preflight compression. It must not patch a return branch, counter, condition, or
result dictionary to force reachability.

## Revised Task 2 gate

- each reachable return has a frozen observable snapshot;
- 10530 and 10542 have a static structural guard instead of fake goldens;

inventory, and do not synthesize invalid transport behavior to preserve the
