## 0. 现状与本轮改动

令牌体系已存在并已进生产：浅色 53 个、暗色 51 个，两边同名。V-1 的工作不是新建，而是
**补齐计划要求的「用途 / 禁止用途」注解，并做此前从未做过的 WCAG 校验**。

本轮据此改了两处值：

| 令牌 | 原值 | 新值 | 原因 |
|---|---|---|---|
| `--desk-glow` / `--veil` / `--veil-strong`（浅色） | `var(--自身)` | `transparent` / `rgba(64,53,79,.28)` / `rgba(64,53,79,.42)` | 自引用导致失效，**浅色主题的书桌渐变自 `2d22fd10` 起一直没有渲染**。生产早已修好，此次回流原型 |
| `--warning`（浅色） | `#A76545` | `#9A5A3C` | 对 `--warning-bg` 仅 3.99:1，**不足 AA**；现 4.69:1 |

## 1. Token 表

每项给出用途与**禁止用途**。禁止用途是这张表的重点——值本身在 CSS 里看得到，用错的方式看不到。

| 令牌 | 浅 / 暗 | 用途 | 禁止用途 |
|---|---|---|---|

| `--ink-strong` | `#4D3C60` / `#F0EAF5` | 标题、当前项、需要被先看见的字 | 不用于长段正文；不用作背景 |

## 2. 承载物性的令牌关系（改值前必须验的等式）

这些关系一旦破坏，界面不会报错，只会**静默说谎**。任何调色都要重验：

| 关系 | 表达什么 | 验证 |
|---|---|---|
| 当前书立标签背景 **===** `--paper` | 这本正打开着，标签和纸连成一体 | 两者 `backgroundColor` 全等 |
| 当前夹标签背景 **===** 夹内纸色 | 同上，Studio 侧 | 全等 |
| `--purple-faint` **明显区别于** `--paper-strong` | 铅笔（未生效）vs 落墨（已确认） | 暗色下蓝通道差 ≥ 15（现为 18） |
| 复印件 `saturate(.55)` + 硬投影 | 这是副本不是原件 | 不得改用虚线（虚线属铅笔家族） |
| 虚线 **只**表示"尚未生效" | 铅笔家族专用 | 复印件、素材堆均不得用虚线 |

## 3. a11y 检查（WCAG 2.1）

实测值，非估算。正文按 AA 4.5:1，大字按 3:1。

### 3.1 浅色主题

| 组合 | 比值 | 结论 |
|---|---|---|
| ink / paper | **10.76** | AAA |
| ink-strong / paper | **9.29** | AAA |
| ink-mid / paper | **6.78** | AA+ |
| ink-soft / paper | **4.82** | AA |
| ink-soft / paper-soft | **4.79** | AA（余量最小，`--ink-soft` 不可再调浅） |
| purple / paper | **6.54** | AA+ |
| surface on purple（紫底白字） | **6.94** | AA+ |
| purple-dark / purple-pale | **8.10** | AAA |
| brown-ink / manila | **4.51** | AA（**临界**，牛皮纸系不可再调） |
| ink-mid / manila | **6.04** | AA+ |
| danger / danger-bg | **7.22** | AAA |
| success / success-bg | **4.97** | AA |
| info / info-bg | **5.00** | AA |
| ~~warning / warning-bg~~ | ~~3.99~~ → **4.69** | 本轮修正 |

### 3.2 暗色主题

全部通过，无一临界：ink 10.56、ink-strong 11.37、ink-mid 7.58、ink-soft 5.12、
purple 5.23、purple-dark/pale 5.56、warning 4.99、danger 6.25、success 5.93、
info 5.92、brown-ink/manila 5.48、ink-mid/manila 5.96。

### 3.3 一个不适用 WCAG 的关系

`--purple-faint` 对 `--paper-strong` 在暗色下只有 **1.04:1**——但这是**两个背景面**的关系，
不是文字对背景，WCAG 不适用。它要满足的是「铅笔面能被看出不同于纸面」，靠色相差承担
（蓝通道差 18）。**不要因为这个数字低就去"修"它**，调高会让铅笔面变成一块突兀的色块。

### 3.4 其他 a11y 事实

- 焦点环：`box-shadow: 0 0 0 3px #fff, 0 0 0 6px #6f4b86` 全局，双层保证在任何底色上可见；
- `prefers-reduced-motion` 已全局兜底（动画 0.01ms）；
- 非颜色语义：状态同时由**文字**承担（练过 / 在学 / 有错题），不单靠颜色；
- 玻璃/纸纹关闭后层级仍在——层级由 `--paper` 三阶与线重承担，不依赖模糊。

## 4. Migration map（原型 ↔ 生产）

**没有名称映射表，因为不需要。**生产 `web/src/index.css` 第 135 行起把原型令牌**逐字**
搬了过去（`--page` / `--ink` / `--paper` / `--desk` / `--purple` / `--manila` …），
原型 CSS 可逐段搬运而不必改写引用。生产此前无裸名自定义属性（`desk.css` 用 `--c-*`，
其余 `--kq-*` / `--hd-*`），无撞名。

### 4.1 三套令牌的分工

| 前缀 | 数量 | 归属 | 状态 |
|---|---|---|---|
| 裸名（`--ink` `--paper` …） | 53 / 51 | **v0.5.0 canonical**，本文管辖 | 现役，扩张中 |
| `--kq-*` | ~40 | 设置页 / onboarding / companion | **过渡态**，未迁移 |
| `--hd-*` / `--color-hd-*` | ~30 | HermesDesk 遗留（间距、语义色、圆角） | 过渡态 |

两套并存是已知过渡态。**新界面一律用裸名那套**；改 `--kq-*` 前先确认该处是否已在迁移范围。

### 4.2 已知双向漂移（必须收口）

| 项 | 原型 | 生产 | 处置 |
|---|---|---|---|
| `--desk-glow` 浅色 | 曾自引用（失效） | `transparent` | **已回流原型**（本轮） |
| `--veil` / `--veil-strong` 浅色 | 曾自引用 | 有效值 | **已回流原型**（本轮） |
| `--lamp-lit` | 无，硬编码在 `.lamp-toggle.is-on svg` | 已提取为令牌 | **待回流**：原型应提取同名令牌 |
| `--warning` 浅色 | `#9A5A3C`（本轮修正） | `#A76545` | **待同步到生产** |

> **流程要求：**原型是声明的真值，但生产已两次先于原型修对。今后任一侧改令牌值，
> 必须同时改另一侧，或在本表登记漂移。否则物性关系会静默失效——`--desk-glow`
> 那次就是：浅色书桌整整若干天没有渲染，而没人发现。
