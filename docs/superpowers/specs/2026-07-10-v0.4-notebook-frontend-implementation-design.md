## 0. 决策摘要

1. v0.4 新增一等路由 `/study/:spaceId?/:page?`；STUDY 不再长期寄居于
   `/chat` 的 264px `WorkspacePanel`。
2. 生命周期页面固定为 **扉页 / 计划 / 学习 / 练习 / 评估**，路由 slug
   固定为 `flyleaf / plan / learn / practice / evaluate`。
3. URL 是课程与页面导航的事实来源；后端 current space 只用于 `/study`
   无参数入口的解析，不再增加一份前端课程选择状态。
4. 每页只消费 owner + space 约束的受信 API。Web 不拼
   `weak_points + quiz.attempt` 证据语义，也不复制草稿状态机。
5. 新旧 UI 只允许短期并存，**同一能力永不双写**：新页落地即把旧可写
   面降为跳转或只读摘要，D-5 删除重复面。
6. v0.4 只实现笔记本信息架构，继续使用 kq-glass；书桌、书立、咖啡杯、
   台灯和 3D 翻页属于 v0.5，不得搭车。
7. D-0 只建立设计、组件测试和性能地基。D-1 代码必须等待 A-R2 与 B-1。

## 1. 当前前端审计

### 1.1 路由与加载

`web/src/main.tsx` 当前同步导入全部页面，仅 `ChatMarkdown` 等局部组件
懒加载；没有 route-level split。`/chat` 同步包含 `WorkspacePanel`，而
`WorkspacePanel` 又同步包含 `StudySection`、`FlashcardPanel` 和
`QuizPanel`。这会让后续 CodeMirror 进入日常聊天初始 chunk，必须在 D-1
前切断。

2026-07-10 D-0 基线（`npm run build`）：

| 产物 | raw | gzip |
|------|----:|-----:|
| `index-*.js` 初始入口 | 1,563.13 kB | 469.59 kB |
| `renderDeck-*.js` | 408.51 kB | 134.97 kB |
| `ChatMarkdown-*.js` | 8.76 kB | 3.25 kB |
| `index-*.css` | 132.70 kB | 21.52 kB |

当前入口已经过大；D 轨不以这份历史体积为放宽理由。D-1 新增路由代码对
`/chat` 初始 gzip 的净增预算为 **5 kB**，`motion` 与 CodeMirror 必须只在
进入 `/study` 或具体练习面后加载。

D-0 测试地基与安全版本更新后的复测为 1,563.48 kB / 469.81 kB gzip，
相对基线仅 +0.22 kB gzip；未引入任何 runtime UI 依赖。依赖审计的
production vulnerabilities 为 0。

### 1.2 现有 STUDY 状态

- `StudySection` 仍编辑 `kabuqina.study.context.v1` 的 12 字段
  localStorage，并同时挂载 Flashcard / Quiz 两个大面板。
- Flashcard 与 Quiz 已使用后端课程空间、草稿、active artifact 和真实
  activity；二者各自维护重复的 spaces/drafts/loading/error 状态。
- `study-api.ts` 是 Tauri invoke 的直接函数集合，组件无法注入 fake
  repository，交互测试成本高。
- 现有 `.test.mjs` 很适合纯 mapper/store，但不能证明路由、焦点、键盘、
  async state 和可访问名称。

### 1.3 必须保留的行为

- M2/M3 已有的 owner/space 隔离、draft → active/rejected、真实
  `flashcard.review` / `quiz.attempt` activity 语义不变。
- 旧 localStorage 在迁移稳定满一个发布周期前只读保留；失败不得清除。
- `/chat` 永远是逃生门，desk child 失效不能让用户困在 STUDY。

## 2. 路由契约

### 2.1 Canonical URLs

```text
/study
/study/:spaceId/flyleaf
/study/:spaceId/plan
/study/:spaceId/learn
/study/:spaceId/practice
/study/:spaceId/evaluate
```

- `/study`：读取 spaces；有 current space 时 `replace` 到其 `flyleaf`，没有
  space 时留在 `/study` 显示开本空态。
- `/study/:spaceId`：规范化为该 space 的 `flyleaf`。
- 非法 page slug：显示路由级 not-found，提供“回到扉页”和“返回聊天”，
  不静默跳到其他页面。
- 不属于当前 owner 的 space、已删除 space：显示不可用恢复面，不泄露该
  id 是否属于别的 owner。
- 页面切换走正常 history；space 切换默认落到目标 space 的同名 page，若
  该页后端能力未就绪则落 `flyleaf`。

### 2.2 Resume 与来源上下文

- D-2 的“继续上次”来自 M4 `current_plan` item；v0.5 才升级为 LG1
  checkpoint。v0.4 不伪造 tutor checkpoint。
- 错题本“再试一次”导航到
  `/study/:spaceId/practice?source=wrongbook&activityId=<opaque-id>`。
- query 只放枚举和 opaque id，不放题目、答案、标题、source excerpt 或
  自由文本；它不会进入 IA 遥测。
- 不新建包含学习内容的 navigation localStorage。URL + 后端 current
  space 已足够恢复。

## 3. 信息架构与页面所有权

| 页面 | 一等内容 | 不属于本页 |
|------|----------|------------|
| 扉页 | active/draft `student_state`、本课目标/偏好/约束 | weak points、系统设置 |
| 计划 | active plan、最近阶段、plan items、继续上次 | 隐藏 planner 推理、远期假计划 |
| 学习 | knowledge base、resource pack、tutoring note、kq-kp | 练习判分、系统导出 |
| 练习 | due cards、quiz、code/derivation 临摹与变式 | 独立/讲解梯级（v0.5） |
| 评估 | 有界错题证据投影、active evaluation、只读 activity 日志 | 人格/能力标签、第三方监控 |

统一草稿箱属于壳级入口；草稿同时在所属页就地出现。两处必须消费同一
query/view-model，不复制 activate/reject 状态机。

## 5. 数据与 view-model 边界

### 5.1 Repository

将直接 `invoke` 包在可注入的 `StudyRepository` 后：

```ts
interface StudyRepository {
  listSpaces(signal?: AbortSignal): Promise<StudySpacesResponse>;
  selectSpace(spaceId: string, signal?: AbortSignal): Promise<void>;
  listDrafts(query: DraftQuery, signal?: AbortSignal): Promise<StudyDraftsResponse>;
  // D-2/D-3/D-4 按后端切片增加类型化方法，不暴露 arbitrary invoke。
}
```

- production adapter 调用现有 Tauri commands；组件测试注入 fake。
- repository 抛出统一的 `StudyRepositoryError`：`unavailable / not-found /
  conflict / invalid / unknown`，保留可重试性，不把 Rust/HTTP 文案直接显示。
- request 支持 AbortSignal 或等价 request generation，space 快速切换时旧响应
  不得覆盖新页面。

### 5.2 壳 view-model

```ts
type StudyPageId = "flyleaf" | "plan" | "learn" | "practice" | "evaluate";

type Loadable<T> =
  | { state: "loading"; previous?: T }
  | { state: "ready"; data: T }
  | { state: "empty"; data?: T }
  | { state: "error"; error: StudyUiError; previous?: T }
  | { state: "degraded"; reason: "desk-unavailable" | "unsupported" }
  | { state: "stale"; data: T; error: StudyUiError };
```

`StudyShellVM` 只含 space 摘要、当前 page、draft count 和可用性；不含题目、
答案、weak-point 文本或大 artifact payload。页面 view-model 在页面 chunk
内构建。

### 5.3 后端必须提供的投影

- D-2 扉页/计划/活动消费 B-1 类型化 API。
- 错题本必须消费 B-5 的有界证据投影；Web 不从 quizzes 与 activities
  自行 join。
- D-4 草稿箱消费 B-5 的 `space/kind/status` query 与统一状态转换。
- code/derivation 普通 payload 不包含 `reference` / `test_code`；D-3 只收
  前端安全 wire shape。

缺失的 API 在相应 D 切片显示 `degraded/unsupported`，不得用 mock 数据
冒充已完成能力。

## 6. 页面状态与 mutation 规则

| 状态 | 视觉与行为 |
|------|------------|
| loading | 保留壳与导航；首次用骨架，刷新时保留 previous，禁止布局跳动 |
| empty | 说明“还没开始”及真实下一步；无错题/无到期卡是积极空态 |
| error | 就地错误、重试、返回聊天；不清空用户输入或 previous data |
| degraded | desk child/能力不可用；不展示 demo；保留聊天逃生门 |
| stale | 显示上次内存数据 + 非阻塞横幅；破坏性/信任边界 mutation 禁用 |

Mutation 规则：

- complete/skip/review/attempt 是直接 activity，不套草稿审批。
- activate/reject 只作用于 artifact draft，必须防双击并按 artifact id 幂等
  刷新。
- mutation 成功后优先 patch 当前 view-model，再后台 revalidate；冲突则以
  后端状态为准并解释，不静默覆盖。
- 未保存表单仅活在页面内存；route 离开前有明确确认。迁移失败继续保留
  旧 localStorage。

## 7. 逐页迁移与双写防线

1. **D-1 壳：** 新路由为开发中入口；旧侧栏仍可使用现有 M2/M3 能力。
2. **D-2 扉页/计划/评估：** 每页上线当天，把旧 profile/plan/evaluation
   写入口改成新路由链接或只读摘要。
3. **D-3 练习：** FlashcardPanel / QuizPanel 改为进入 PracticePage；旧面
   不再提交 review/attempt。
4. **D-4 学习/草稿箱：** 知识与草稿管理迁入；高级治理功能只在菜单中。
5. **D-5：** 删除重复面、legacy read path 与临时兼容组件。

任何 PR 若让同一 mutation 同时存在于新旧两处，必须拒绝合并。

## 8. 响应式与降级布局

以容器宽度而非设备名定义：

| 内容宽度 | 布局 |
|---------:|------|
| `>= 960px` | top bar + 横向五标签；正文最大 880px，可有轻量页边列 |
| `640..959px` | 横向可滚动标签；正文单列；页边注进入正文后的 aside |
| `< 640px` | 紧凑 top bar；space switcher 为 dialog；标签保留文字且可横滚 |

- 不把五页藏进 hamburger；物件/页面始终可发现。
- 200% 缩放下不得产生双轴页面滚动；表格可在自身容器横滚。
- 读屏/窄窗看到的是普通文档布局，纸张隐喻不是理解或操作前提。

## 9. 键盘、焦点与动效

- 生命周期 nav 使用链接语义；当前页有 `aria-current="page"`。
- route 完成后焦点落页面 `h1`（`tabIndex=-1`），后退恢复触发链接。
- space switcher、草稿箱 dialog 遵守 focus trap、Escape、关闭后归还焦点。
- 练习焦点域内：Space 翻卡，1/2/3/4 评分；输入框、CodeMirror、按钮聚焦
  时全局 handler 不生效。
- 所有 mutation 可纯键盘完成；不依赖 hover 才显示关键操作。
- View Transitions 不可用时直接切换；`prefers-reduced-motion` 下取消位移、
  翻转和热气动画，仅保留必要 opacity。

## 10. 视觉 token 的 v0.4 使用边界

- Style Tile 的 `--kq-scene-*` 是 v0.5 场景规范源，D-1 不把 desk/paper/
  noise 全量注入产品根主题。
- v0.4 壳沿用 `--kq-color-*`、`--kq-glass-*`、现有 radii 和 shadows。
- 可读草稿与警示可引用 Style Tile 已验证值：light pencil `#7d61a0`、
  muted `#7a6494`、warn `#a8472f`；dark 使用对应表值。实现时建立
  `--kq-study-*` 语义别名，避免组件复制 hex。
- 首个 lifecycle 图标是“扉页”，不是设置齿轮。
- 小娜杯只留在 Style Tile 作 v0.5 品牌兼容参考；v0.4 的“问小娜”使用
  文本 + 现有普通图标，不生产新杯子资产。

## 11. 性能与懒加载门

1. `StudyRoute` 必须由 `React.lazy` / dynamic import 形成独立 route chunk。
2. D-1 壳不得 import CodeMirror、练习生成器、KaTeX CSS 的新副本或
   `motion` 的全包入口。
3. `motion` 只在 STUDY chunk 消费；优先 `motion/react` tree-shakable API。
4. CodeMirror 按 surface 导入必要包，形成独立 `study-codemirror-*` chunk。
5. `/chat` 初始 gzip 相对 D-0 基线净增 <= 5 kB；CodeMirror chunk 对
   `/chat` 的静态/动态依赖图均为零。
6. 每个 D 切片记录 `dist/assets` raw+gzip；超过预算必须解释或拆分，不能
   只提高 Vite warning limit。

## 12. 测试架构

D-0 引入 Vitest + Testing Library + user-event + jsdom，仅作为组件/路由
runner；现有 `.test.mjs` mapper/store 测试保留。

测试层级：

- **pure：** 现有 node:test，覆盖 mapper、normalize、storage migration。
- **component：** Vitest/jsdom，覆盖 loading/empty/error/stale、表单、
  activate/reject、键盘和 accessible name。
- **route：** memory router + fake `StudyRepository`，覆盖 canonical redirect、
  invalid page、space switch、来源 query、焦点。
- **manual WebView2：** D-5 覆盖真实 Tauri invoke、窗口尺寸、主题、缩放、
  离线和老版本迁移。

合并门：新交互组件必须至少有 happy path、失败保持数据、纯键盘三类断言；
禁止用读取源码字符串替代交互断言。

## 13. IA 遥测边界（D-5 实现）
