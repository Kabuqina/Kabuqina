# v0.5.0 Study 五页空置状态合同

> 日期：2026-07-31
> 状态：`FIRST PASS · PRODUCT CONTRACT`
> 范围：扉页、计划、学习、练习、评估五页的初始空置、处理中、失败、失效与部分可用状态
> 依赖：Study 五页行为规格、Study 知识核编译器实施计划

## 0. 为什么单独定义

空置状态不是“没有数据时放一句暂无内容”。它必须回答：

1. 当前缺少什么；
2. 为什么这里还不能开始；
3. 用户此刻最合适的下一步是什么；
4. 哪些已有数据仍然安全；
5. 小娜是否真的需要介入。

五页依赖链不同，不能统一显示“问小娜”：

```text
知识源
  → 可靠目录
  → 学习计划
  → 知识核草稿
  → 用户采用的知识核
  → 同核练习
  → 可追溯练习证据
  → 评估与回访
```

扉页不在这条强制依赖链上。目标、偏好和约束均可留白，不阻止用户使用其他页面。

## 1. 全局状态模型

`StudyPageState` 不是一个把所有情况塞在一起的单枚举。实现必须分别派生**读取阶段**、
**领域内容状态**和**瞬时标记**；有多个独立区域的页面还要为每个区域单独派生状态。

### 1.1 读取阶段

| 阶段 | 含义 | 展示原则 |
|---|---|---|
| `initial` | 数据尚未请求 | 不显示空态 |
| `loading` | 首次读取中，且没有可信旧数据 | 保持页面骨架，不闪现“暂无内容” |
| `ready` | 本轮读取成功 | 根据领域内容状态展示 |
| `error` | 首次读取失败，且没有可信旧数据 | 说明暂不可用并提供读取重试 |

### 1.2 领域内容状态

| 状态 | 含义 | 展示原则 |
|---|---|---|
| `ready-empty` | 请求成功，确实没有所需领域对象 | 显示本页专属空态和主动作 |
| `ready-content` | 已有可用领域对象 | 正常显示内容 |
| `working` | 后台正在生成、编译或检查 | 显示具体对象和阶段，不重复提交 |
| `draft-ready` | 有待用户确认的草稿 | 主动作指向查看/采用，不重新生成 |
| `operation-failed` | 生成、编译、检查或其他领域动作失败 | 保留上下文，提供该动作的重试 |
| `operation-cancelled` | 可取消的领域动作已经取消 | 不显示为完成；允许重新发起 |
| `target-invalid` | 原题、知识核、目录节点或导航位置已失效 | 只在当前课程内按合同逐级降级 |

`target-invalid` 专指领域对象或导航目标失效，不用于描述网络刷新失败。刷新失败但仍有可信旧数据
时，旧数据称为 **retained content**，继续按原领域状态展示。

### 1.3 瞬时标记与部分可用

以下信息与读取阶段、领域状态正交，不得覆盖页面主内容：

| 标记 | 含义 | 展示原则 |
|---|---|---|
| `refreshing` | 已有内容正在刷新 | 保留可信旧内容，只显示轻量刷新状态 |
| `refresh-error-with-data` | 刷新失败，但仍有可信旧数据 | 保留旧内容，显示局部重试提示 |
| `mutation-pending` | 当前动作正在提交 | 只锁相关动作，不冻结整页 |

`partial` 是页面组合结果，不是单个内容区的主状态。例如评估与错题独立加载时，一边
`ready-content`、另一边 `error`，页面整体为 partial，但两个区域各自展示自己的状态。

### 1.4 派生与优先级

同一内容区只显示一个主状态：

```text
无可信数据的读取 error
  > 无可信数据的首次 loading
  > target-invalid
  > 已采用的 ready-content
  > draft-ready
  > working
  > operation-failed
  > operation-cancelled
  > ready-empty
```

同一目标已有 active 对象时，active 对象是领域真值；历史 run 或失败不能覆盖它。没有 active
对象时，按“可审核草稿 → 最新进行中 run → 最新失败/取消 → 确实为空”派生。计划页、评估页等
包含多个独立区域时，此优先级对每个区域分别应用。

`refreshing`、`refresh-error-with-data` 和 `mutation-pending` 只作为附加标记，不进入上述
互斥优先级。

### 1.5 动作层级

每个空态最多：

- 一个主动作；
- 两个次动作；
- 一个非阻塞说明。

主动作必须直接补上最近的缺失前提：

| 缺失前提 | 主动作 |
|---|---|
| 没有知识源 | `添加知识源` |
| 有知识源，没有计划 | `+ 学习计划` |
| 有知识核草稿 | `查看知识核` |
| 有 active 知识核 | `学习` 或 `练习` |
| 当前知识核没有练习 | `准备练习` |
| 没有评估证据 | `去练习` |

“问小娜”默认是次动作，只用于解释、重整或处理异常；不能代替系统本应提供的创建、编译、
重试或打开入口。

这里的“问小娜”指自由求助入口。`+ 学习计划` 打开带固定上下文和待采用产物合同的小娜面板，
属于受约束的计划创建流程，不等同于用自由聊天代替系统入口。

## 2. 共同文案规则

空态文案使用：

```text
标题：当前缺少的领域对象
说明：为什么需要它，不描述内部实现
主动作：动词 + 对象
```

示例：

```text
还没有学习计划
知识源已经准备好了，可以据此安排接下来的学习与练习。
[+ 学习计划]
```

禁止：

- “数据为空”“artifact 不存在”“knowledge core unavailable”等内部语言；
- 把系统失败写成用户做错了；
- 用“恭喜”“值得庆祝”解释尚未开始；
- 暗示打开、阅读、生成或采用即代表掌握；
- 显示覆盖率、完成百分比、连续天数或能力徽章；
- 无上下文地只放“问小娜”；
- loading 时先渲染空态再跳成真实内容。

## 3. 扉页

扉页没有传统空态。首次打开就显示三个固定输入行：

- 我的目标；
- 我的偏好；
- 时间与约束。

### F-EMPTY：尚未填写

表现：

- 三行保持真正空白，不自动填提示性答案；
- 不显示大面积空态卡片；
- 不显示“请先填写才能继续”；
- 不跳 Chat；
- 字段不是必填项。

动作：

- 主动作：`确认并生效`；
- 次动作：`放弃修改`；
- 次动作：`请小娜帮我拟一版`。

如果三项均为空，用户仍可离开本页；系统不得自动生成或保存虚构偏好。

### F-WORKING：小娜正在拟定

- 保留当前三行内容；
- 显示“正在根据当前填写内容拟一版”；
- 不锁用户编辑；
- 新建议回来时先形成可查看建议，不覆盖用户期间的新输入。

### F-ERROR：保存或建议失败

- 保存失败保留输入值；
- 主动作：`重试保存`；
- 小娜失败不影响手动填写；
- 不以失败结果清空本地恢复草稿。

## 4. 计划页

计划页的真实前提依次是知识源、可靠目录、计划草稿、active 计划。

### P-EMPTY-0：没有知识源

标题：`先放入知识源`

说明：`计划需要依据真实材料安排；添加教材、讲义或习题集后再开始。`

动作：

- 主动作：`添加知识源`，打开材料导入；
- 次动作：`问小娜`，只解释如何选择材料。

不得显示空白目录或默认计划。

### P-EMPTY-1：有知识源，但没有可靠目录

标题：`还需要确认材料结构`

说明：`这份材料没有可直接使用的目录。先确认学习范围，再据此拟定计划。`

这不阻止用户点击 `+ 学习计划`。计划可以依据所选文件生成行动阶段，但这些阶段只能称为
学习计划，不能冒充原文件目录。模型推断目录必须另行成为待确认结构，不能直接变成来源目录。

### P-EMPTY-2：有目录，没有 active 计划或计划草稿

标题：`还没有学习计划`

说明：`知识源已经准备好了，可以据此安排接下来的学习与练习。`

动作：

- 主动作：`+ 学习计划`；
- 次动作：`打开知识源`。

点击 `+ 学习计划`：

- 先读取知识源中的 active 文件，只按 `resource_pack` 文件计数，不把知识卡片或辅导笔记算成文件；
- 恰好一份文件时，直接以这份文件为唯一依据启动计划草稿生成；
- 两份或以上时，先在计划页列出文件名，用户选择一份后再启动生成；
- 如果读取成功但文件数为零，显示“知识源里还没有文件”，并提供 `上传资料`；不得写成读取失败；
- 只有文件列表请求失败时才显示暂时无法读取和重试；
- 生成请求自动带入当前课程、扉页设定、被选文件和其真实来源引用，不再要求用户重复发送一遍；
- 一次生成只绑定一份被选文件，不暗中混入其他知识源；
- 计划始终先成为 draft，不自动采用。

正式计划与草稿列表必须共同判定页面主状态。正式计划请求尚未完成时，不得先显示草稿；
点击采用后立即隐藏草稿并显示单一的“正在采用学习计划…”状态，直到正式计划返回，不得闪回草稿或
“+ 学习计划”空态。

计划被“不采用”后回到此状态。被拒绝的草稿不自动恢复，也不阻止再次生成。

### P-WORKING：计划正在拟定

- 标题：`正在拟定学习计划`；
- 保留真实材料目录；
- 展示最近一个可理解的阶段，不展示工具调用细节；
- 主动作禁用并显示 `正在拟定…`；
- 次动作：`查看进行中` 或 `取消`，前提是运行支持取消。

### P-GENERATION-FAILED：计划拟定失败

- 保留知识源、可靠目录和用户已经填写的扉页设定；
- 标题：`学习计划暂时没有拟定完成`；
- 不展示内部错误或工具调用；
- 主动作：`重新拟定`；
- 次动作：`打开知识源`；
- 模型或凭据不可用时，可额外提供明确的 `前往设置`，替代无效重试。

重试创建新 run；失败 run 只用于诊断和展示，不恢复成计划草稿。

### P-CANCELLED：计划拟定已取消

- 标题：`已取消拟定学习计划`；
- 不显示为“拟定完成”；
- 主动作：`+ 学习计划`；
- 次动作：`打开知识源`。

### P-DRAFT：计划草稿已生成

- 没有 active 计划时，计划页主体完整展示待采用的计划草稿；
- 主动作：`采用计划`；
- 次动作：`不采用`；
- 草稿中的行动只用于预览，在采用前不显示 `学习 / 练习` 等执行按钮，也不能建立继续位置；
- 采用成功后，同一位置切换为正式计划，草稿标题、说明和采用动作全部消失；
- active 计划是页面真值；即使草稿列表刷新尚未完成，也不得在正式计划上方继续显示草稿链接或提示；
- 第一版不依赖独立“草稿箱”入口完成计划审核；
- 审核时不再运行通用 AI“检查并采用”；
- 采用时只做 schema、真实目录节点和 mode 等确定性校验。

### P-PARTIAL：active 计划已有，但节点没有知识核

按知识核编译器状态显示：

| 编译状态 | 节点动作 |
|---|---|
| 未请求 | `整理知识核` |
| queued / reading / generating / validating | `正在整理…` |
| draft_ready | `查看知识核` |
| needs_source | `指定知识源` |
| failed | `重新整理` |
| cancelled | `重新整理`，并显示“已取消整理” |
| active core 存在 | `学习` |

active core 是该节点的优先真值；存在 active core 时，历史 run 不覆盖 `学习`。小娜只出现在
`needs_source / failed` 的次动作中。`cancelled` 不得仅根据 Activity 的公共 `completed`
投影显示为完成。

### P-COMPLETE：当前计划所有行动已结束

标题：`这一轮计划已经结束`

说明：`完成行动不代表已经掌握；可以回看评估证据，或根据当前情况拟定下一轮计划。`

动作：

- 主动作：`+ 新一轮计划`；
- 次动作：`查看评估`。

## 5. 学习页

学习页的主对象是一个已采用的知识核，不是目录或资料列表。

### L-EMPTY-0：没有计划范围

标题：`先确定学习范围`

说明：`学习页一次只处理一个知识核。先在计划页选择这一段要学什么。`

动作：

- 主动作：`回到计划`；
- 如果计划也不存在，计划页继续显示 `+ 学习计划`。

### L-WORKING：当前节点正在编译知识核

标题：`正在整理这一节`

说明：显示真实目录节点名称，不显示内部 run 状态。

动作：

- 主动作：`查看进行中`；
- 次动作：`打开知识源`。

页面不得在编译期间显示“当前范围还没有知识核”。

### L-DRAFT：知识核草稿待采用

标题：`这一节的知识核已经整理好`

动作：

- 主动作：`查看知识核`；
- 次动作：`打开知识源`。

未采用知识核不能进入学习页主体。

### L-EMPTY-1：编译结束但没有可采用知识核

按原因显示：

- `needs_source`：`这部分还缺少可定位的知识源`；
- `failed` 或编译无结果：`这部分暂时没有整理出可靠知识核`；
- `cancelled`：`已经取消整理这一节`；
- 用户拒绝草稿：`这一节还没有采用的知识核`。

动作：

- 主动作随原因选择 `指定知识源` 或 `重新整理`；
- 次动作：`回到计划`；
- 次动作：`问小娜`。

### L-TARGET-INVALID：当前知识核失效

降级顺序：

1. 同一目录节点最近有效知识核；
2. 同一目录节点的计划位置；
3. 当前课程计划页。

不得跳到其他节点或其他课程。用户自己的学习草稿保留并说明可以恢复。

## 6. 练习页

练习页必须先有 active 知识核，再有明确绑定到该知识核的题。

### R-EMPTY-0：没有当前知识核

标题：`先选择要练习的知识核`

说明：`练习不会借用其他学习范围的题目。`

动作：

- 主动作：`回到学习`；
- 次动作：`回到计划`。

### R-WORKING：当前知识核的练习正在准备

标题：`正在准备这一步的练习`

- 保留当前知识核标题；
- 不切换到其他知识核；
- 主动作：`查看进行中`；
- 次动作：`回到学习`。

### R-PREPARATION-FAILED：练习准备失败

- 保留当前知识核标题和来源范围；
- 标题：`这一步的练习暂时没有准备好`；
- 不借用其他知识核的题，也不把失败结果激活为练习；
- 主动作：`重新准备`；
- 次动作：`打开知识源`；
- 次动作：`回到学习`。

重试创建新的准备 run；旧的失败 run 不产生题目或练习证据。

### R-PREPARATION-CANCELLED：练习准备已取消

仅在准备流程支持取消或运行被明确标记为 cancelled 时使用：

- 保留当前知识核；
- 标题：`已取消准备练习`；
- 不显示为“练习草稿已经准备好”；
- 主动作：`准备练习`；
- 次动作：`回到学习`。

### R-DRAFT：有练习草稿但尚未采用

标题：`练习草稿已经准备好`

动作：

- 主动作：`查看练习草稿`；
- 次动作：`回到学习`。

### R-EMPTY-1：当前知识核没有练习

标题：`这一步还没有可用练习`

说明：`系统会优先从知识源中选择合适题目；没有合适原题时，再生成待采用的补充题。`

动作：

- 主动作：`准备练习`；
- 次动作：`打开知识源`；
- 次动作：`回到学习`。

`准备练习` 不是“自动采用题目”。材料原题或生成题仍按 S3E 来源和审核合同进入可用状态。

### R-EMPTY-2：有知识核，但知识源不足以出题

标题：`这一步还缺少可用题目来源`

动作：

- 主动作：`添加知识源`；
- 次动作：`问小娜`；
- 次动作：`回到学习`。

不得借用其他知识核的题来填空。

### R-TARGET-INVALID：原题或知识核失效

- 原题失效：留在同一知识核的练习入口；
- 知识核失效：降级到同一目录节点；
- 保留未提交答案的本地恢复副本；
- 不把失效题提交为新证据。

## 7. 评估页

评估页只消费有来源的练习证据。阅读、计划完成和知识核编译都不产生评估结论。

### E-EMPTY-0：没有练习证据

当错题本和最近评估均为空时，合并成一个页面级空态：

标题：`还没有可以评估的练习证据`

说明：`完成一次可检查的练习后，这里会保留需要回访的证据和调整建议。`

动作：

- 主动作：`去练习`；
- 次动作：`回到学习`。

不得显示“错题本为空，值得庆祝”，因为用户可能尚未开始练习。

### E-PARTIAL-0：有练习证据，没有评估

- 正常显示错题与回访入口；
- “最近评估”区域显示：`还没有形成评估`；
- 不把没有评估描述成加载失败；
- 主动作仍是具体的 `重做这题` 或 `回学习`。

### E-PARTIAL-1：有评估，没有错题

- 显示有来源的评估；
- 错题区域显示：`当前没有需要回访的错题`；
- 不推断“已经掌握”。

### E-TARGET-INVALID：评估证据失效

- 没有有效 `evidence_refs` 的评估不用于调整；
- 原题失效降级到同一知识核；
- 知识核失效降级到同一目录节点；
- 仍可显示评估标题，但明确“来源已不可定位”，不展示为当前结论。

### E-ERROR：局部读取失败

错题和评估独立加载：

- 一部分失败时保留另一部分；
- 每个失败区各自重试；
- 不用一个全页错误覆盖仍有效证据。

## 8. 页面间动作合同

| 来源页 | 动作 | 目标 | 必须保留 |
|---|---|---|---|
| 计划 | `+ 学习计划` | 计划页右侧小娜 | space、扉页设定、知识源、目录 |
| 计划 | `查看知识核` | 草稿审核 | outline node、draft id |
| 学习 | `回到计划` | 当前课程计划页 | outline node、plan item |
| 学习 | `查看进行中` | 进行中面板 | compilation run |
| 练习 | `准备练习` | 当前页准备状态 | knowledge core、source scope |
| 练习 | `回到学习` | 同一知识核学习页 | knowledgeCoreId |
| 评估 | `去练习` | 当前或最近有效知识核练习页 | knowledgeCoreId（如存在） |
| 评估 | `重做这题` | 原题 | activityId、exerciseId、knowledgeCoreId |

任何动作的精确目标失效时，按“题 → 知识核 → 目录节点 → 当前课程计划页”逐级降级。

## 9. 第一版实现顺序

1. 建立共享 `StudyPageState` 派生规则，避免各页自行猜测；
2. 计划页补 `添加知识源 / + 学习计划 / 编译完整状态`；
3. 学习页接知识核编译的 working、draft-ready、needs-source、failed 和 cancelled；
4. 练习页补无核、准备中、失败/取消、草稿、无题和来源不足；
5. 评估页合并真正的“零证据”空态；
6. 扉页只补 loading/error，不增加大空态；
7. 统一 loading 不闪空态、target-invalid 降级、retained content 和局部重试。
