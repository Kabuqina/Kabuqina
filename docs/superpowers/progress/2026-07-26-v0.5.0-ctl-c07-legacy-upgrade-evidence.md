## Outcome

C07 now has one user-visible, fail-closed path for v0.4 messaging data:
inventory → verified local export → explicit exact cleanup. Removed or unknown
records are not redirected to Desktop or another retained channel. This is
source/fixture upgrade evidence; CTL-G01/Q still owns the official installed
artifact upgrade matrix.

## Implemented contract

| Surface | Result |
|---|---|
| host/profile env | inventory exposes key names only; cleanup rewrites a frozen exact-key allowlist after export verification; shared retained `TWILIO_*` credentials are excluded |
| export snapshot | every current cleanup candidate path and SHA-256 must match the export before the first rewrite; added, removed or changed data forces a new export |
| QQ home alias | `QQ_HOME_CHANNEL{,_NAME}` copies to `QQBOT_` only during the explicit action and only when canonical is absent |
| config/directory | removed `platforms` entries are deleted structurally; retained and unknown sibling data survives |
| exact runtime state | finite Feishu/WeCom QR, Feishu state, removed pairing/thread-map and known profile files are removable; symlinks are refused |
| directories/history | production code has no walk or recursive delete; sessions, jobs, media, unknown files and profile directories remain |
| pairing limits | only keys whose parsed platform is in the fixed removed set are rewritten |
| cron | raw old destination stays visible and deletable, receives an unavailable badge, and still executes as `unsupported_delivery` without reroute |
| sessions | an unknown stored platform becomes `PersistedPlatformValue`, round-trips its original text, and cannot become a live `Platform` or `local` |
| WhatsApp | a sole legacy session tree is atomically renamed to the canonical path; when both exist, only canonical is writable and legacy is identity-read fallback |
| QQ voice temp | decoder failure removes the temporary source and any partial WAV output |
| Settings routes | v0.4 `/settings/feishu` and `/settings/wecom` are tombstones linking to the legacy-data control, not redirects to retained channels |
| home rename state | inventory reports canonical/legacy-home coexistence and the UI explains that this control does not merge or recursively delete either tree |

Exports are content-addressed SHA-256 JSON files below the app data
`legacy-channel-exports` directory. Each included file has its own SHA-256 and
base64 body. A file over 16 MiB, a total over 64 MiB, a changed home path, a
bad export hash, a malformed JSON record, a changed cleanup snapshot, or a
missing confirmation refuses cleanup before the first rewrite. A rejected
cleanup invalidates the Web authorization and requires another export.
