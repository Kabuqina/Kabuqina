## 3. Crash, race, and restart evidence

- spawned coordinator owner crash 留下 durable fence/journal，由新 coordinator 实例接管；
- spawned Gateway production constructor 与独立 desk-style LearningStore writer 同时命中 owner fence，
  两者均返回 `LearningOperationInProgressError / learning_operation_in_progress`；
- delete restart matrix 覆盖 `fenced → learning_deleted → runtime_deleted → compacted` 四个 crash phase；
- full import restart rollback matrix 覆盖
  `fenced → validated_empty → learning_imported → runtime_imported` 四个 crash phase；
- stable outbox 覆盖 learning projection 已提交、ack 前 crash 的 replay，不复制 terminal event；
- prepare hash drift、manifest mismatch、oversize 与 runtime merge fingerprint conflict 均为 zero-delete/zero-partial-write。
