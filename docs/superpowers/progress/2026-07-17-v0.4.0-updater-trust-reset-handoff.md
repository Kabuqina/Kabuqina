## 1. 背景与锁定结论

v0.3.0 发布后，旧 updater private key 的密码无法恢复，也没有可继续使用的 private key。Tauri updater 把 public key 固定在已安装应用中；没有匹配的 private key，就无法给旧安装签发可验证的自动更新。

因此：

- v0.2/v0.3 用户必须手工运行 v0.4.0 NSIS 一次。
- v0.4.0 嵌入新 public key，成为 updater v2 信任链起点。
- v0.5.0 及以后必须继续用匹配的新 private key 签名。
- 旧 latest.json 通道冻结，不得放入用新 key 签名的 manifest/artifact。
- 新通道统一使用 latest-v2.json，COS 优先、GitHub fallback。
- updater key 与 Windows Authenticode 代码签名证书是两套独立凭据。

Tauri 官方参考：https://v2.tauri.app/plugin/updater/
