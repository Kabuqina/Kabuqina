## 5. 四个共享边界

### 5.1 WeCom crypto 与 Weixin

`wecom_crypto.py` 当前服务 WeCom callback 路径；Weixin 有自己的 crypto/media 逻辑。删除
WeCom 前必须先证明 import graph，并在删后重跑 retained Weixin QR、media、encryption 与
bundle smoke，不能用“文件名都含 we”判断共享性。

### 5.2 Discord media/voice 与 WhatsApp/Telegram

通用 media/cache/audio/SSRF 合同位于 gateway base/shared 路径，Discord 还承载 voice
特有覆盖。删除 Discord 测试前，先把 retained media、audio、document、URL safety 合同
转移到 WhatsApp/Telegram 等 retained adapter 测试。

### 5.3 SMS home 与 Email

Rust Email profile 仍复制 `SMS_`/`TWILIO_`，Web Email 设置仍写 `SMS_HOME_CHANNEL`，而
Email runtime 的 canonical home 是 `EMAIL_HOME_ADDRESS`。旧 SMS job 不迁移成 Email；
它必须保持可列举/编辑/删除，并明确返回 `unsupported_delivery`。

### 5.4 Webhook/API Server 与 Desktop loopback

Webhook/API Server 是公开 gateway adapter。Desktop 是 Tauri shell + 随机 loopback
desk-server/HMAC bridge，既不是 Webhook/API Server，也不是 `Platform.LOCAL`。删除两个
公开 adapter 后必须保留 Desktop desk-server、bridge、chat 和 HMAC smoke。
