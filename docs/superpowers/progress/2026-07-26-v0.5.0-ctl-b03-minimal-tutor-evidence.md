## 1. 交付结论

B03 已把 B02 lifecycle/runtime store 接成一个独立、可恢复、硬预算的 L-2 Tutor 纵向闭环：

- `start` 最多执行一次 explanation provider attempt，随后以 host-owned learner check interrupt；
- `continue` 零模型调用并以 `participation_only` 完成；
- 第一次 `explain_again` 最多执行一次 remediate attempt，第二个 check 只接受 `continue`；
- invalid/stale/duplicate answer、cancel、terminal resume 均不会产生额外 provider request；
- provider request 前先 durable reserve，SDK retry=0、fallback=0；crash 遗留 reservation 结算为
  `unknown`，不退款、不重发；
- desk start/resume 已启用真实 engine，恢复时只重绑已冻结 plan，不重新 auto-detect；
- 普通 Agent graph、Gateway Tutor、Web Study、B02 DB schema 和 Rust wire 均未修改。

L-2 不包含 grader、correctness、mastery 或 weak-points 推断。模型只生成受限 explanation/remediate
正文，分支由 host option 与持久化 phase 确定。

## 3. 冻结合同证据

### 3.1 Deterministic graph

`TutorGraphStateV1` 验证 graph/checkpoint version、phase、node/attempt/check caps、fixed provider plan
与 hash。host 创建两个固定 check：check 1 为 `continue|explain_again`，check 2 只含 `continue`。
invalid option reissue 同一 check；terminal snapshot immutable。`completion_basis` 固定为
`participation_only`。

Tutor LangGraph 仅在 `tutor_builder.py` import/compile，runtime object 不进入持久化 state。普通 Agent
graph 的 plain-text、protocol parity 与 error parity 回归全部通过。

### 3.2 Provider、预算与 secret 边界

`TutorProviderPlanV1` 只保存公开的 provider/model/api-mode/endpoint identity 与 canonical hash；
userinfo、query secret keys、command providers、OAuth 网络 mint 路径和 native Gemini endpoint 均在
create/rebind 前 fail closed。凭据只在执行时本地重绑，不进入 checkpoint、run、event 或 error detail。

OpenAI/Anthropic client 显式 `max_retries=0`，每次 `execute_once()` 至多一个 HTTP request，不调用
`call_llm()`，也没有 provider/model/credential fallback。reservation 覆盖完整 canonical UTF-8 wire
input（≤16,384 bytes）、output 2,048 和 wall 35,000 ms；active segment 45 s、activity 120 s，并为
settlement/finalize 保留 10 s。remaining ≤10 s 时在 reservation 前 blocked。

每个 physical attempt 先 commit B02 write-ahead reservation，再执行 transport，随后 settle。普通
exception 在 terminal commit 前持久化 typed blocked；模拟 process crash 的 `BaseException` 保留
`reserved`，fresh-process reconciliation 转 `unknown`，该 segment 不重发。

### 3.3 Lifecycle、identity 与跨进程恢复

`TutorActivityExecutor` 只调用 B02 public store/service APIs：create/idempotency、execution claim、answer
claim、reservation/settlement、interrupt/terminal 与 abandoned reconciliation。四元 identity、canonical
request fingerprint、revision CAS、payload mismatch conflict 和 terminal outbox 仍由 B02 合同拥有。

desktop route 使用进程内 live-execution registry 保护当前调用，同时每次 trusted service construction
都对不在 live snapshot 的 abandoned run 做恢复。start/resume 是同步 worker 调用，不阻塞 FastAPI
event loop。restart 后 running → interrupted；cancel/stale/duplicate/terminal path 不再进入 provider。
