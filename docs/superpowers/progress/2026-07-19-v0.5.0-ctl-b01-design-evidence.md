## 2. Observed-source evidence

| 事实 | 核验来源 | 设计影响 |
|---|---|---|
| 普通 Agent graph 编译时无 checkpointer | `hermes_core/agent/graph_engine/engine.py`、`builder.py` | 新 Tutor graph 独立；不扩展 `TurnState` |
| `call_llm` 不暴露物理 attempt reservation，且 resolver/client 路径含 retry/fallback 行为 | `hermes_core/providers/chat_completions.py` | Tutor 禁止包 `call_llm`；用 SDK retry=0、fallback=0 的 single-attempt port |
| `learning.db` 已有 WAL/busy/secure-delete，但 v0.4 schema reader 不拒绝高版本 | `hermes_core/learning/learning_store.py::_init_schema` | Tutor 使用独立 `tutor_runtime.db`，不升级 learning.db |
| v0.4 owner delete 只枚举五张 v1 表 | `LearningStore.delete_owner_data()` | v0.5 增加 composite delete；禁止未 prepare 降级 |
| `learning_activities` 是 append-only event | 同上 schema 与 `insert_activity()` | runtime terminal 用 outbox 投影，不改旧读者语义 |
| desk、Gateway、cron 分别直接构造 `LearningStore()`，是不同 Python 进程/入口 | `python/src/desk_server/routes/study_routes.py`、`hermes_core/gateway/study_commands.py`、`hermes_core/cron/scheduler.py` | fence 必须位于 core 的 shared coordinator，所有 store writer 强制参加 |
| 上游 L-2 要求 `terminal completed 或一次 remediate → learner_check` | `docs/superpowers/plans/2026-07-17-v0.5.0-development-plan.md` §L-2 | L-2 保留一次 learner-controlled remediate，不做未经批准的 scope change |
| owner 由 desktop runtime 注入 | `python/src/learning_owner.py`、Study routes | public wire 不接受 owner id |
| Study Rust bridge 已独立 | `tauri/src/study.rs` | L-1 增加同族 command，不在 Web 直连 Python |
| 现有 `/study/activities` 是历史摘要 | `python/src/desk_server/routes/study_routes.py` | 新 API 使用 `/activity-runs`，不破坏旧 endpoint |
| core v1 import cap 为 16 MiB，Rust file cap 为 10 MiB | `learning_store.py::import_owner_bundle`、`tauri/src/study.rs` | BundleV2 统一 24 MiB，全层同一 byte 口径 |
| bundle config 声明 `allowDowngrades=false` | `tauri/tauri.conf.json` | 只作为实现事实；Q-3 仍需真实 v0.5→v0.4 artifact 验证 |

## 4. Review findings closure（v2）

| Finding | 修订结论 | 设计位置 |
|---|---|---|
| P1 降级安全 | 独立 `tutor_runtime.db`；不支持原地降级；composite delete、prepare/recovery、真实 v0.4 red characterization | §6.1、§6.4 |
| P1 模型硬预算 | single-attempt provider port；SDK retry=0/fallback=0；调用前 durable reservation；crash unknown 不退款 | §6.2、§6.3、§7.1 |
| P1 确定性评价 | L-2 收缩为 acknowledgement/participation-only；trusted rubric/result/provenance/branch-v1 冻结供 L-3 | §5.2–§5.3 |
| P2 identity/idempotency | DB/API 统一四元 identity；scoped idempotency + RFC 8785 SHA-256 fingerprint；异 payload conflict | §3.2–§3.4、§6.2 |
| P2 export/import | BundleV2 全层 24 MiB；checkpoint/owner/terminal 子 cap；near-cap round-trip 与零部分写入 | §6.5 |

## 5. Review findings closure（v3）

| Finding | 修订结论 | 设计位置 |
|---|---|---|
| P1 跨进程 fence | 新增 shared `learning_coordination.db`；所有 desk/Gateway/cron `LearningStore` 读写先取 guard；operation lease、锁序与 crash phase 冻结 | §2、§6.2–§6.4 |
| P1 L-2 上游冲突 | 不改上游 scope；host-defined `continue/explain_again` choice 确定性完成或最多一次 remediate；仍为 participation-only、无 correctness | §5.1–§5.3、§10.2 |
| P1 downgrade restore | BundleV2 增加 `tutor_runtime_merge`；当前 learning 数据可非空且永不覆盖；冲突全批零写入、missing source 保留为 blocked | §6.4–§6.5 |
| P2 terminal schema | run 表补齐 completion basis、remediation count 与六个 numeric budget columns；terminal commit/attempt folding 顺序冻结 | §3.5、§6.2–§6.3 |
| P2 deadline/recovery | provider timeout 降至 35 s；每次调用保留 10 s finalize；120 s active deadline 与 crash wall reservation 持久化；CAS 文案按 control path 区分 | §4.1、§7.1 |
