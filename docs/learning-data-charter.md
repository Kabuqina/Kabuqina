## 前言

学习数据（learning.db）积累的是一个学生最私密的东西：他不会什么、
他错在哪。一个学生愿意把自己的弱点摊开给小娜看，这份信任就是整个
产品。本宪章的目的：**技术上防泄露，承诺上防变质，伦理上防背叛。**

## 第一条 · 学习内容永不离开设备

学习数据保存在本机，不上传。遥测**只计数、永不引用**：任何遥测事件
可以包含派生数字（回合长度、知识点发射率、复习完成率），永远不得
包含学习内容本身（题目、答案、错误、笔记、材料摘录）。此规则须有
测试断言守护，不靠自觉。

若未来提供云同步：端到端加密、默认关闭、密钥由学习者持有。

## 第二条 · 数据权利属于学习者

学习者对自己的全部学习数据享有：**可见**（透明可查，无隐藏字段）、
**可改**（学习状态可编辑）、**可导出**（标准格式带走）、**可彻底
删除**（一键清空，不留残余）。这四项是产品功能，不是客服流程。

## 第三条 · 数据永不反过来对付学生

- 不给学习者贴固定能力标签（已由 learning contract 强制并有测试锁定）；
- evaluation 只做基于证据的观察，不做人格或能力定性（M4 契约）；
- 记录薄弱点的唯一目的是帮他补，任何让学生看到自己数据时感到被审判
  而非被理解的功能，都是错的；
- 空态是尊严的一部分：「无错题」是值得庆祝的画面，不是缺数据的遗憾。

## 第四条 · 分享只能由学习者本人发起

任何第三方视图——无论家长、辅导员、导师、教师、院系——只能由学习者
主动发起分享或导出。产品永远不内置面向权力方的监控面。群聊等多人
场景下，学习空间按发送者隔离（既有 gateway owner 语义），同群成员
互不可见。

一个学生若知道错题本会被权力方看见，他就再也不会诚实地错了。

## 第五条 · 她只为学生服务（C 端身份条款）

小娜是 C 端产品。**她从来不是为老师/导师而生，她本来就是为学生而生。**

若产品成功，B 端与教育机构必然找上门。届时本条生效：

- 学习者的失败数据可见性**永不出售**——包括作为任何 B2B 合同、校园
  采购、班级版授权的一部分；
- 「给老师一个后台看看学生薄弱点分布」类需求，无论报价多少，答案在
  2026 年已经写好：不做；
- 若未来确有教学改进类的聚合需求（如匿名课程难点热力图），必须满足：
  不可回溯到个人 + 学习者知情且 opt-in + 不作为购买方的验收条件。

付钱的人可以是学校，服务的人永远是学生。二者冲突时，学生赢。

## 技术落实清单（v0.4.0 起）

| 项 | 内容 | 归属 |
|----|------|------|
| T1 | 验证 learning.db 的 ACL 实际生效（四层 §8.2 的设计承诺→实现核查） | B-1 或独立小补丁 |
| T2 | 遥测「只计数不引用」测试断言（扫描实际 serialized event，不得含学习内容） | H5 + D-5 lifecycle IA |
| T3 | 一键彻底删除 + 标准导出入口 | B-5（M6 高级菜单） |
| T4 | source_refs 摘录的最小化上限持续执行（自洽不等于囤积） | 契约既有,回归守护 |

**T1 完成记录（2026-07-10）：** 默认 production `learning.db` 在首次
打开前收紧父目录权限，使 SQLite `-wal` / `-shm` 继承同一策略；Windows
移除继承 ACL 并仅授予当前登录主体 full-control，POSIX 使用目录 0700 / 文件
0600。实效测试读取操作系统 ACL/模式，而不是只断言调用发生。

**T3/T4 完成记录（2026-07-12）：** 一键删除在 SQL `DELETE` 后不会立即
报告成功：数据库连接启用 SQLite `secure_delete`，再执行 WAL checkpoint/truncate、
`VACUUM`、最终 WAL truncate；回归测试关闭连接后扫描主库、`-wal` 与 `-shm`，
确认私密 sentinel 不残留。标准导入严格校验空间状态及 current 标志；`source_refs`
的数值字段必须有限且有界，拒绝 NaN/Infinity。

**T2 完成记录（2026-07-16，pre-A-R3）：** H5 的 agent `UsageEvent` 与 D-5 的
Web lifecycle IA 保持两个独立事件族。D-5 运行时 serializer 只接受八个批准名称及
`page`、`action`、`success`、`count_bucket` 白名单字段；未知名称/字段、对象/数组、
title/answer/id/source_refs/prompt sentinel 均被拒绝。生产 sink 默认关闭，只在本机
累加有限枚举计数，不调用 Tauri/network；opt-out 清除 aggregate，sink throw/reject
不影响学习操作。最终 release bundle 仍需在 A-R3 后复核 test sink 未进入产物。
