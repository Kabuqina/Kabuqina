# STUDY 模块工作流测试说明

## 覆盖范围

本测试覆盖 STUDY 面板的赛题 A3 学习工作流：

- 对话式学习画像构建
- 个性化学习路径规划
- 课程知识库 / 初始文档集构建
- 多智能体资源包生成
- 智能辅导答疑
- 学习效果评估

## 自动化测试

在 `web/` 目录执行：

```powershell
npm.cmd run test:chat-ux
npm.cmd run build
```

通过标准：

- `test:chat-ux` 通过，确认 STUDY 面板暴露 6 个动作。
- 每个提示词包含“不编造未知信息”和“不使用 emoji”的约束。
- 学习画像提示词要求不少于 6 个维度和“已确认 / 待确认 / 推断”标注。
- 课程知识库提示词要求初始知识库 / 文档集、分层知识结构、版权/许可字段和防幻觉规则。
- 资源包提示词要求多智能体协同、至少 5 类学习资源和防幻觉检查。
- 智能辅导提示词要求文字解释、步骤化推理、图解/思维导图大纲。
- 学习效果评估提示词要求至少 6 个评估维度和动态调整方案。
- `build` 通过，确认 TypeScript 与 Vite 构建无错误。

## 手工测试流程

启动应用后进入聊天页，打开右侧工作区并切换到 `STUDY`。

### 1. 构建学习画像

点击“构建学习画像”。

测试输入：

```text
我是计算机专业大二学生，正在学机器学习。目标是 4 周内掌握监督学习基础，能完成一个 sklearn 分类实验。我线性代数一般，Python 会基础语法，但模型评估指标经常混淆。每天大概能学 1 小时，喜欢代码例子和图示。
```

预期结果：

- 输出至少 6 个画像维度。
- 每个维度标注“已确认 / 待确认 / 推断”。
- 缺失信息进入“不确定信息”或类似区域。
- 不把未提供的成绩、教材、学习历史写成事实。

### 2. 生成学习路径

在已有画像上下文后点击“生成学习路径”。

预期结果：

- 输出阶段路线表。
- 包含每日/每周任务、资源推荐、练习安排、检查点。
- 每个任务有预计耗时、前置条件和完成标准。
- 对推断内容说明依据。

### 3. 课程知识库

点击“课程知识库”。

测试输入：

```text
课程名称是《机器学习基础》，面向计算机专业大二学生。希望覆盖监督学习、模型评估、逻辑回归、决策树、朴素贝叶斯和聚类入门。已有资料包括课程 PPT、实验指导书和几份 sklearn 示例代码。希望知识库既支持讲解生成，也支持练习题和代码实验生成。
```

预期结果：

- 输出课程目标与边界。
- 输出课程目录与知识图谱。
- 包含“课程 -> 单元 -> 知识点 -> 子技能 -> 典型误区 -> 可验证练习”的结构。
- 导入材料字段包含标题、来源、类型、章节、知识点标签、适用水平、可信度、版权/许可、人工核验状态。
- 包含质量核验与防幻觉规则。

### 4. 生成资源包

点击“生成资源包”。

测试输入：

```text
主题聚焦在机器学习中的逻辑回归，我希望资源包适合 1 周学习，包含讲解、练习和代码实验。
```

预期结果：

- 明确列出多智能体协同过程。
- 至少生成 5 类资源：讲解文档、思维导图、分层练习、拓展阅读、代码/实验案例。
- 练习题分基础、进阶、应用三档。
- 代码/实验案例包含目标、输入或数据、关键步骤、预期输出和检查点。
- 包含质量检查与不确定信息。

### 5. 智能辅导答疑

点击“智能辅导答疑”。

测试输入：

```text
我不理解逻辑回归为什么输出的是概率，也不清楚 sigmoid 函数和决策边界是什么关系。
```

预期结果：

- 先复述问题和已知条件。
- 给出文字解释、步骤化推理、图解/思维导图大纲。
- 如果给视频/动画，只能给脚本大纲，不能声称已经生成视频文件。
- 能根据画像或上下文调整难度。

### 6. 学习效果评估

点击“学习效果评估”。

测试输入：

```text
我完成了 20 道逻辑回归练习，基础题 8/10，进阶题 5/8，应用题 1/2。代码实验能跑通，但我还是分不清 precision、recall 和 F1。
```

预期结果：

- 覆盖至少 6 个评估维度。
- 每个维度给出证据来源或待确认说明。
- 输出画像更新建议、学习路径调整、资源推送策略。
- 数据不足时设计小测评，不编造分数。

## 边界测试

- 在没有任何上下文时点击各按钮，应先追问关键信息。
- 输入空泛请求，例如“帮我学 AI”，应要求补充课程、目标、基础、时间等信息。
- 输入明显缺失来源的资料要求时，应标注“待确认”，不能写成事实。
- 输入超长上下文时，界面应保持可用，生成提示词仍应围绕关键信息。
