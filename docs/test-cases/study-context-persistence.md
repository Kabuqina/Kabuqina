# STUDY 学习上下文持久化测试说明

## 覆盖范围

本测试覆盖 STUDY 面板的本地持久化学习上下文：

- 课程/专业方向
- 学习目标
- 画像摘要
- 短板/易错点
- 偏好/时间
- 学习进度
- 练习/反馈

这些字段会保存到本机 `localStorage`，并在点击 STUDY 工作流按钮时注入提示词，作为学习画像、学习路径、资源生成和学习效果评估的输入。

## 自动化测试

在 `web/` 目录执行：

```powershell
npm.cmd run test:study-store
npm.cmd run test:chat-ux
npm.cmd run build
```

通过标准：

- `test:study-store` 通过，确认：
  - 空上下文返回默认空对象。
  - 非字符串字段会被清理为空字符串。
  - 字段前后空白会被裁剪。
  - 单字段最多保留 800 字符。
  - 无效 JSON 不会导致崩溃，会回退为空上下文。
  - 保存、读取、清空行为符合预期。
  - 格式化后的提示词只包含非空字段。
- `test:chat-ux` 通过，确认 STUDY 面板引用 `loadStudyContext`、`saveStudyContext`、`clearStudyContext` 和 `formatStudyContextForPrompt`。
- `build` 通过，确认 UI 和类型检查无错误。

## 手工测试流程

启动应用后进入聊天页，打开右侧工作区并切换到 `STUDY`。

### 1. 保存上下文

填写以下字段：

```text
课程/专业方向：机器学习基础，计算机专业大二
学习目标：4 周内掌握监督学习并完成 sklearn 分类实验
画像摘要：Python 基础可用，线性代数一般，偏好代码示例
短板/易错点：precision、recall、F1 混淆
偏好/时间：每天 1 小时，喜欢图示和实操项目
学习进度：已完成逻辑回归讲解和 20 道练习
练习/反馈：基础题 8/10，进阶题 5/8，F1 仍混淆
```

点击“保存上下文”。

预期结果：

- 按钮文字短暂变为“已保存”。
- 切换到其他页面再回到 STUDY，字段仍保留。
- 重启前端页面后字段仍保留。

### 2. 注入工作流

保存上下文后点击“学习效果评估”。

预期结果：

- 小娜应优先使用已保存的学习进度和练习/反馈。
- 输出不应再要求重复输入已经保存的信息。
- 如果需要更细数据，可以继续追问，但必须说明缺口。

### 3. 清空上下文

点击清空按钮。

预期结果：

- 所有字段清空。
- 再次点击任一 STUDY 工作流时，应按无上下文情况先追问关键信息。

## 边界测试

- 输入超长文本：单字段超过 800 字符后，保存时会裁剪，应用不应卡顿。
- 输入只有空格：保存后应视为空字段。
- 清空后刷新页面：字段应保持为空。
- localStorage 不可用或损坏：应用不应崩溃，STUDY 面板应正常显示空上下文。

## 数据安全说明

- 学习上下文仅保存在本机 WebView 的 `localStorage` 中。
- 不包含 API Key，不写入普通项目配置文件。
- 上下文会被拼进发给模型的提示词，因此不要填写不希望发送给模型服务商的隐私信息。
