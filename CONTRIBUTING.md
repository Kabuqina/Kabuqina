# Contributing

Thank you for contributing to Kabuqina.

By submitting a pull request, patch, issue attachment, or other contribution to
this repository, you agree that your contribution is licensed under the Apache
License 2.0.

Please make sure that your contribution is your own work, or that you have the
right to submit it under the Apache License 2.0.

AI-assisted code is allowed, but contributors are responsible for reviewing,
testing, and ensuring that submitted work does not knowingly include copied
third-party code with incompatible licenses.

## Pull Requests

- Keep changes focused and explain the reason for the change.
- Include tests or verification notes when behavior changes.
- Do not include secrets, API keys, credentials, or private user data.
- Respect the architecture boundaries documented in `AGENTS.md`.
